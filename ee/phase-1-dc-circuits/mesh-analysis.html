Mesh Analysis Explorer

Mesh analysis is the systematic way to solve a circuit with more than one independent loop. Instead of guessing branch currents and chasing them through KCL/KVL by hand, you assign a "mesh current" to each window of the planar circuit, write one KVL equation per window, and you've got an N×N matrix equation. The matrix can be written by inspection — no algebra — once you see the pattern. This explorer shows the 2-mesh and 3-mesh cases, with the matrix appearing live as you change resistor values.

Three things to take away: (1) each mesh gets one current variable, conventionally drawn clockwise — that single convention removes 90 % of the sign confusion; (2) the matrix has a fixed structure — the diagonal is the sum of all resistors in mesh k, the off-diagonal is the negative of any shared resistor between mesh j and mesh k, and the RHS is the sum of voltage sources driving mesh k clockwise; (3) once you've solved for mesh currents, any branch current is either one mesh current (if the branch is on the outside) or the difference of two mesh currents (if the branch is shared between meshes).

The systematic procedure

1. Identify the meshes (independent loops with no other loop inside them). 2. Assign a mesh current I_k to each, all clockwise (this is the universal sign convention). 3. For each mesh, walk it clockwise writing KVL: ΣV across resistors = ΣV sources driving the mesh clockwise. 4. Voltage across a resistor in mesh k: R · I_k if the resistor is only in mesh k, or R · (I_k − I_other) if shared. 5. Stack the equations into matrix form: → R · I = V, where R is N×N, I and V are N×1. 6. Solve by Cramer's rule, Gaussian elimination, or — at N=2 — direct substitution.

The "by inspection" pattern (no algebra needed)

For any planar circuit with N meshes and all currents drawn clockwise:

R[k][k] (diagonal): sum of all resistors that border mesh k. Always positive. R[j][k] (off-diagonal, j ≠ k): negative sum of resistors shared between mesh j and mesh k. Always non-positive. Zero if the meshes don't touch. V[k] (RHS): sum of voltage sources in mesh k that push current clockwise (so the negative terminal is "behind" you as you walk clockwise). Source flipped → flip the sign. Symmetry: For circuits with only independent sources and resistors, R[j][k] = R[k][j]. The matrix is symmetric — easy to check your work.

Worked example — 2-mesh circuit step-by-step

The setup

Two windows. V1 = 10 V in the left mesh, V2 = 5 V in the right mesh, both pointed to push their respective mesh clockwise. R1 = 100 Ω in left only, R3 = 330 Ω in right only, R2 = 220 Ω shared between them (the middle branch).

Write KVL for mesh 1 (clockwise)

Walk clockwise: start at V1's negative terminal, go up through V1 (gain +10), right across R1 (drop = +100·I1), down through R2 (drop = +220·(I1 − I2)), back to start. KVL: −10 + 100·I1 + 220·(I1 − I2) = 0 Collect: (100 + 220)·I1 − 220·I2 = 10 → 320·I1 − 220·I2 = 10

Write KVL for mesh 2 (clockwise)

Walk clockwise: up through R2 (drop = +220·(I2 − I1)), right through R3 (drop = +330·I2), down through V2 (gain or drop depends on polarity — here V2 pushes mesh 2 clockwise, so it's a gain of +5). KVL: 220·(I2 − I1) + 330·I2 − 5 = 0 Collect: −220·I1 + (220 + 330)·I2 = 5 → −220·I1 + 550·I2 = 5

Stack into matrix form

[ 320 −220 ] [ I1 ] [ 10 ] [ −220 550 ] [ I2 ] = [ 5 ]

Compare with the "by inspection" pattern: diagonal = sum of mesh resistors (320 = 100+220, 550 = 220+330). Off-diagonal = −R_shared = −220. RHS = source pushing clockwise in that mesh. You didn't need to write KVL at all — the matrix entries are visible directly in the schematic.

Solve (Cramer's rule)

det = 320·550 − (−220)·(−220) = 176,000 − 48,400 = 127,600 I1 = (10·550 − (−220)·5) / det = (5500 + 1100) / 127,600 = 51.7 mA I2 = (320·5 − (−220)·10) / det = (1600 + 2200) / 127,600 = 29.8 mA

Recover branch currents

I_R1 = I1 = 51.7 mA (R1 is in mesh 1 only) I_R3 = I2 = 29.8 mA (R3 is in mesh 2 only) I_R2 = I1 − I2 = 21.9 mA (R2 is shared; net current flows downward in the middle branch)

Worked example — 3-mesh circuit with the inspection trick

The setup

Three side-by-side meshes. V1 = 12 V drives mesh 1, V2 = 6 V drives mesh 2, V3 = 0 V (mesh 3 has no source). R1 = 100 Ω (mesh 1 only), R2 = 200 Ω (shared 1↔2), R3 = 300 Ω (mesh 2 only), R4 = 400 Ω (shared 2↔3), R5 = 500 Ω (mesh 3 only).

Build the matrix by inspection — no KVL writing

R[1][1] = 100 + 200 = 300 (R1 + R2 border mesh 1) R[2][2] = 200 + 300 + 400 = 900 (R2 + R3 + R4 border mesh 2) R[3][3] = 400 + 500 = 900 (R4 + R5 border mesh 3) R[1][2] = R[2][1] = −200 (−R2 shared) R[1][3] = R[3][1] = 0 (meshes 1 and 3 don't touch) R[2][3] = R[3][2] = −400 (−R4 shared) V = [12, 6, 0]ᵀ (sources driving each mesh clockwise)

Matrix

[ 300 −200 0 ] [ I1 ] [ 12 ] [−200 900 −400 ] [ I2 ] = [ 6 ] [ 0 −400 900 ] [ I3 ] [ 0 ]

Solve (Gaussian, or just plug into the explorer)

I1 ≈ 55.8 mA, I2 ≈ 23.8 mA, I3 ≈ 10.6 mA Branch I_R2 = I1 − I2 = 32.0 mA (flows in mesh 1's direction through R2) Branch I_R4 = I2 − I3 = 13.2 mA (flows in mesh 2's direction through R4) Check: 300·0.0558 − 200·0.0238 = 11.98 ≈ 12 ✓ · -200·0.0558 + 900·0.0238 − 400·0.0106 = 6.02 ≈ 6 ✓ · -400·0.0238 + 900·0.0106 = 0.02 ≈ 0 ✓

What to notice

  • The matrix is symmetric for resistor-only circuits. R[j][k] = R[k][j]. If your computed matrix isn't symmetric, you made a sign error on a shared resistor or forgot the clockwise convention.
  • Diagonal dominates. R[k][k] ≥ Σ|R[j][k]| for j ≠ k (with equality only at the boundary). This means the system is well-conditioned and easy to solve numerically. Almost any iterative solver converges quickly.
  • Off-diagonals are zero between non-adjacent meshes. In the 3-mesh example, R[1][3] = 0 because meshes 1 and 3 don't share a branch. This is what makes large mesh matrices sparse, which is why mesh analysis scales to thousands of nodes in SPICE.
  • Reversing a source's polarity flips its RHS sign. Try setting V1 = −10 V; the mesh currents flow the opposite direction. The matrix on the left is unchanged.
  • Setting R2 = 0 (a short) doesn't crash the matrix — it just makes the diagonal smaller and the off-diagonal vanish, effectively merging the two meshes into one. Setting R2 = ∞ (open) does the opposite: the meshes decouple completely (R[1][2] → 0).
  • Mesh analysis only works for planar circuits (circuits you can draw on paper without crossings). For non-planar (3D / graph-theoretic) circuits, nodal analysis is the only general technique. Most board-level circuits are planar, so this isn't a practical limitation.

Where you'll see this technique

Real uses

  • SPICE itself — the modified nodal analysis (MNA) inside every SPICE solver is a generalization of these matrix equations.
  • Power distribution networks — current flow through a multi-loop ground-plane is mesh analysis.
  • Wheatstone bridges — the classic 3-mesh problem; balance condition pops out of the matrix solution.
  • Resistor networks for measurement — Kelvin / 4-wire sense circuits, R-2R ladder DACs.
  • Hand verification — when SPICE gives you a weird answer on a small circuit, mesh analysis is the fastest sanity check.
  • Cross-link: see Nodal Analysis Explorer for the dual technique.

Cheat sheet

FORMULAS

System
R · I = V
Diagonal
R[k][k] = ΣR in mesh k
Off-diag
R[j][k] = −R_shared(j,k)
RHS
V[k] = ΣV driving CW
Branch (only in k)
I_branch = I_k
Branch (shared j,k)
I_branch = I_j − I_k
2x2 inverse
[a b; c d]⁻¹ = (1/det)·[d −b; −c a]
2x2 det
det = ad − bc

PROCEDURE

  • All mesh currents clockwise.
  • Diagonal = sum of border resistors.
  • Off-diag = −shared resistor (or 0).
  • RHS = sum of CW-driving voltage sources.
  • Symmetric matrix → check by hand-flipping.
  • Branch current = mesh or mesh-minus-mesh.

COMMON PITFALLS

  • Mixing CW and CCW — pick one and stick. CW is the universal convention.
  • Forgetting the minus on shared R — off-diagonals are always non-positive.
  • Source polarity — V_k is positive if the source pushes that mesh CW. Reversed → negate.
  • Current source in a mesh — needs a supermesh (combine the two meshes the current source bridges). This explorer keeps to voltage-source-only circuits for clarity.
  • Non-planar circuit — you can't draw it without crossings, so you can't identify meshes. Use nodal.
  • Power-balance sanity — total source power must equal total resistor dissipation. Always check.
