Nodal Analysis Explorer

Nodal analysis is the systematic dual of mesh analysis: pick a reference node (ground), assign a voltage to every other node, and write one KCL equation per node. The result is a conductance-matrix equation G·V = I with the same "by inspection" structure as the mesh matrix — but built from conductances (1/R) and current sources instead of resistances and voltage sources. This is the technique SPICE actually uses internally (modified nodal analysis, MNA), and the one to reach for whenever current sources dominate or the circuit has many loops but few nodes (op-amp circuits, transistor amplifiers).

Three things to take away: (1) node voltages are referenced to ground — pick the ground node by convention (the largest plane, or the negative supply, or wherever your scope ground will clip), and every other node is "potential relative to that"; (2) the conductance matrix has a fixed pattern — diagonal G[k][k] = sum of conductances touching node k, off-diagonal G[j][k] = negative of conductance between j and k, RHS I[k] = net current injected into node k; (3) the dual table — voltage ↔ current, resistance ↔ conductance, mesh ↔ node, KVL ↔ KCL — turns nodal analysis into "mesh with the labels swapped," which is why both techniques are taught together.

The systematic procedure

1. Pick a reference node (call it ground, V = 0). Every other node gets a labeled voltage V_k. 2. For each non-reference node, write KCL: Σ currents leaving the node = Σ currents injected into the node. 3. Current through a resistor from node j to node k is (V_j − V_k) / R — flowing from j to k if V_j > V_k. 4. Stack into matrix form: → G · V = I, where G is N×N (N = non-reference nodes), V is the column of node voltages, I is the column of injected currents. 5. Solve. Branch currents come from (V_j − V_k)/R afterwards.

The "by inspection" pattern (no algebra needed)

G[k][k] (diagonal): sum of all conductances touching node k (including resistors to ground). Always positive. G[j][k] (off-diagonal, j ≠ k): negative sum of conductances directly between j and k. Always non-positive. Zero if no direct R between them. I[k] (RHS): net current flowing into node k from external sources (current sources, or voltage-source–through–series-resistor converted via Norton). Symmetric: G[j][k] = G[k][j] for resistor-only networks. Same as mesh — symmetric matrices factor cheaply.

Worked example — 2-node circuit step-by-step

The setup

Two non-reference nodes connected to ground through resistors, and to each other through a middle resistor. Current sources inject I1 = 10 mA into node 1 and I2 = 5 mA into node 2. R1 = 100 Ω (node 1 → gnd), R2 = 220 Ω (node 1 → node 2), R3 = 330 Ω (node 2 → gnd).

Write KCL at node 1

Current leaving node 1 to ground (through R1): V_1 / 100 Current leaving node 1 to node 2 (through R2): (V_1 − V_2) / 220 Current injected: 0.010 A KCL: V_1/100 + (V_1 − V_2)/220 = 0.010 Collect: (1/100 + 1/220)·V_1 − (1/220)·V_2 = 0.010 In conductance: (0.010 + 0.00455)·V_1 − 0.00455·V_2 = 0.010

Write KCL at node 2

Currents leaving node 2: through R2 toward node 1 (V_2 − V_1)/220, through R3 toward gnd V_2/330 KCL: (V_2 − V_1)/220 + V_2/330 = 0.005 Collect: −(1/220)·V_1 + (1/220 + 1/330)·V_2 = 0.005

Matrix form (G · V = I)

[ 0.01455 −0.00455 ] [ V_1 ] [ 0.010 ] [ −0.00455 0.00758 ] [ V_2 ] = [ 0.005 ]

By inspection: G[1][1] = 1/R1 + 1/R2 = 0.01455 S. G[2][2] = 1/R2 + 1/R3 = 0.00758 S. G[1][2] = −1/R2 = −0.00455 S. No algebra needed — the matrix is read directly from the schematic.

Solve

det = 0.01455 · 0.00758 − (−0.00455)² = 1.103·10⁻⁴ − 2.07·10⁻⁵ = 8.96·10⁻⁵ V_1 = (0.010·0.00758 − (−0.00455)·0.005) / det = (7.58 + 2.275)·10⁻⁵ / 8.96·10⁻⁵ = 1.10 V V_2 = (0.01455·0.005 − (−0.00455)·0.010) / det = (7.275 + 4.55)·10⁻⁵ / 8.96·10⁻⁵ = 1.32 V

Recover branch currents

I_R1 = V_1/100 = 11.0 mA (node 1 → gnd) I_R2 = (V_1 − V_2)/220 = (1.10 − 1.32)/220 = −1.00 mA (actually flowing node 2 → node 1) I_R3 = V_2/330 = 4.00 mA (node 2 → gnd) Sanity: KCL at node 1: 10 mA in = 11 mA out R1 − 1 mA out R2 → 10 mA. ✓

Worked example — 3-node ladder by inspection

The setup

3 nodes connected in series to ground through R1, R3, R5 (one shunt per node) and chained to each other by R2 and R4. I1 = 10 mA into node 1, I2 = 5 mA into node 2, I3 = 0 mA into node 3. R1 = 100, R2 = 200, R3 = 300, R4 = 400, R5 = 500.

Matrix by inspection

G[1][1] = 1/100 + 1/200 = 0.015 S (R1 and R2 touch node 1) G[2][2] = 1/200 + 1/300 + 1/400 = 0.01083 S (R2, R3, R4 touch node 2) G[3][3] = 1/400 + 1/500 = 0.0045 S (R4 and R5 touch node 3) G[1][2] = G[2][1] = −1/200 = −0.005 S G[1][3] = G[3][1] = 0 (no direct R between nodes 1 and 3) G[2][3] = G[3][2] = −1/400 = −0.0025 S

What to notice

  • Set the reference smartly. The "ground" node is just a label — you can pick any node. Choose the one with the most connections (largest plane in a real layout), the most resistors going to ground, or the node whose voltage you don't need. Smaller matrix, fewer unknowns.
  • Negative node voltages are fine. If a current source pulls current out of a node (negative injection), the node voltage goes negative. This is the dual of "voltage source reversed → mesh current reverses."
  • Branch current sign tells you direction. Compute I_branch = (V_high − V_low) / R using your node labels. If you get a negative number, the actual flow is the other direction. Don't second-guess — let the algebra carry the sign.
  • Conductance form is "more natural" for nodal. Nodal analysis lives in conductance space (G = 1/R, units siemens) the way mesh lives in resistance space. Datasheets sometimes give Y-parameters (admittance) directly because they're the nodal-matrix entries for a black box.
  • Op-amps love nodal. An ideal op-amp enforces V+ = V− (virtual short) — that's just a constraint between two nodes, naturally fitting into the nodal equations. Mesh analysis with op-amps is awkward because the loop currents depend on the supply rails.
  • Voltage source between two non-reference nodes → supernode. You merge the two nodes into one and add the constraint V_j − V_k = V_source. This explorer keeps to current-source-only circuits for clarity, but the technique generalizes.

Where you'll see this technique

Real uses

  • SPICE / LTspice internals — every simulator solves G·V = I (with extra rows for inductors/voltage sources). This is modified nodal analysis (MNA).
  • Op-amp circuit hand analysis — golden rules + KCL at the summing junction = closed-form gain.
  • Power-distribution networks (PDN) — DC IR-drop analysis on a power plane is exactly nodal analysis on a 2D resistor mesh.
  • Transistor small-signal models — hybrid-π is naturally drawn as nodal admittances.
  • FEA / heat-flow analogues — node voltage ↔ temperature, current ↔ heat flux, conductance ↔ thermal conductance. Same matrix, different units.
  • Cross-link: see Mesh Analysis Explorer for the dual technique, and Source Transformations for the bridge that lets you switch between them.

Cheat sheet

FORMULAS

System
G · V = I
Diagonal
G[k][k] = Σ G touching node k
Off-diag
G[j][k] = − G_between(j,k)
RHS
I[k] = injected into k
Branch I
I_jk = (V_j − V_k) / R_jk
Conductance
G = 1 / R, in siemens (S)
2x2 det
det = ad − bc

PROCEDURE

  • Pick the ground node (V=0).
  • Label every other node V_k.
  • Diagonal = Σ conductances at node.
  • Off-diag = −G between nodes.
  • RHS = net current injected.
  • Solve, then branch I = ΔV/R.

COMMON PITFALLS

  • Forgetting the minus on off-diagonals. Conductance between nodes goes in with a negative sign.
  • Mixing R and G in the same matrix. Stay in conductance throughout; convert once at the end if needed.
  • Voltage source between two non-ground nodes → use a supernode (merge them, add a constraint).
  • Sign of injected current — pulling current out is negative injection. Easy to flip.
  • Op-amp output as a node — yes, it's a node, but the op-amp's output stage sources/sinks current to maintain V+ = V−, so it acts like an ideal voltage source. Use a supernode or substitute the virtual-short constraint.
  • Floating sub-network — if a sub-circuit has no DC path to ground, its node voltage is undefined. Always sanity check.
