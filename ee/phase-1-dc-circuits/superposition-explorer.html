Superposition Explorer

Two voltage sources feed a shared 100 Ω resistor through 50 Ω paths. Toggle each source on/off. Verify voltage superposes — but power does NOT.

Regime & assumptions

Regime
linear network DC steady-state linear elements only
Assumes
Every element in the circuit is linear (R, ideal L, ideal C); when "turning off" a source, voltage sources become short circuits, current sources become open circuits; instantaneous response (no time-dependence beyond steady-state)
Breaks down when
Any nonlinear element is present — a diode, BJT in cutoff/saturation, or saturating core — voltage and current no longer superpose; power never superposes even in linear circuits because P = V · I has a cross-term (Ptotal ≠ P1 + P2); transient analysis with initial energy storage complicates the "turn off" step (need to also zero the initial conditions)

Superposition works for linear quantities: voltage, current, charge. Apply each source one at a time, then add. It does not work for power, because P = V²/R is nonlinear. This is the most common trap in early circuit analysis — the visual computes both and shows the gap, so you see why, not just that it's so.

ΔP = 192 mW (actual − sum). They disagree because P ∝ V², and (V1+V2)² ≠ V1² + V2² — the cross term 2·V1·V2 is missing from the sum.

Why power fails — the algebra

With both sources on, V_R = V_a + V_b (superposition for voltage).
Power: P_total = (V_a + V_b)² / R = (V_a² + 2·V_a·V_b + V_b²) / R
= P_a + P_b + 2·V_a·V_b / R ← cross term, lost when you sum P_a + P_b alone.

Live values: V_a = 4.00, V_b = 2.40, cross = 2·V_a·V_b/R = 192 mW — matches ΔP above.

Rule: never superpose power. Always find total V or I first, then compute P once.

What to notice

  • Voltage and current superpose — find each source's contribution alone, add them, done.
  • Power does not superpose — the cross term 2·V_a·V_b/R is always present and is what the naïve sum misses.
  • Sign of the cross term — same polarity sources → cross term adds to P_actual; opposing polarity → cross term subtracts. Try setting V2 with opposite polarity by sliding it through zero.
  • Deactivating a source means: V → short (0 V wire), I → open (no current path). The visual short-circuits the source when its checkbox is off.
  • Superposition is only useful when linear — diodes, transistors, and any nonlinear element break the assumption.
  • The shortcut for one branch — if you only want V across one resistor, superposition can be faster than full nodal analysis.

Cheat sheet

FORMULAS

V superposes
V_total = Σ V_k (each source alone)
I superposes
I_total = Σ I_k
Power does NOT
P_total = V_total² / R (compute once)
Power gap
ΔP = 2·V_a·V_b / R (cross term)

METHOD

  • Linear circuits only — no diodes, no transistors at large signal.
  • Deactivate: V → short, I → open. One source at a time.
  • Sum the V (or I), then compute P from the total — never sum P.
  • Sign matters — same polarity adds the cross term; opposing subtracts.

COMMON PITFALLS

  • Σ P_k ≠ P_total — P is quadratic in V. The cross term 2·V_a·V_b/R is missing from the naïve sum.
  • Forgetting the dependent sources — independent sources deactivate; dependent stay on (they track the new circuit state).
  • Wasted effort — if there are only two sources and you need everything, nodal/mesh is usually faster than superposition.
