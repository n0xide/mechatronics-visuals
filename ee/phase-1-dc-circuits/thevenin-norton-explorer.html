Thévenin & Norton Explorer

A two-terminal "black box" with one source and two resistors. Compute V_oc, I_sc, Thévenin (V_th + R_th), Norton (I_n ‖ R_n). Sweep R_load and see the max-power-transfer peak at R_load = R_th.

Thévenin and Norton both say the same thing: any linear two-terminal network looks like one source + one resistor to whatever you connect to it. Thévenin uses a voltage source, Norton uses a current source — they're algebraically interchangeable via the source-transformation rule. This makes load analysis tractable: you don't redo the whole network every time R_load changes.

Pick Thévenin for series-load analysis, Norton for parallel-source analysis. Either works.

Max power transfer — P(R_load)

Current load: R_load = 150 Ω, delivers P = 110 mW. Peak P_max = V_th² / (4·R_th) = 112 mW at R_load = R_th.

What to notice

  • V_oc and I_sc are the only two measurements you need — every property of the equivalent comes from them: V_th = V_oc, I_n = I_sc, R_th = V_oc/I_sc.
  • R_th = R_n always — the resistor value is the same in both equivalents. Only the source type and topology change.
  • Max power at R_load = R_th — set R_load below or above and power drops. Try sweeping R_load to find the peak; it sits exactly where the curve's slope is zero.
  • P_max = V_th² / (4·R_th) — derived by setting dP/dR_load = 0. Half the source's available power is dissipated in R_th itself at the match point.
  • Equivalents work at the terminals only — inside the box, currents are different. Don't mix up "what's inside" with "what the load sees."
  • Source transformation is your friend — a hairy network with both V and I sources often collapses to a single Thévenin after a few transforms.

Cheat sheet

FORMULAS

V_th
V_th = V_oc (terminals open)
I_n
I_n = I_sc (terminals shorted)
R_th
R_th = R_n = V_oc / I_sc
Transform
V_th = I_n · R_th
Max power
R_load = R_th → P_max = V_th² / (4·R_th)

DEACTIVATION RULES

  • V source → short (replace with a wire).
  • I source → open (replace with a break).
  • R_th by inspection — kill all independent sources, look back into the terminals, simplify with series/parallel.
  • Half-power at match — half delivered to R_load, half burned in R_th.

COMMON PITFALLS

  • Dependent sources don't deactivate — apply a test source (1 V or 1 A), find the response, R_th = V_test / I_test. Never short or open them.
  • Equivalent only valid at the terminals — currents inside the original box differ from inside the equivalent. Don't probe internal nodes.
  • Max-power transfer ≠ max efficiency — at the match, efficiency is only 50%. For power supplies, you want R_load ≫ R_th.
