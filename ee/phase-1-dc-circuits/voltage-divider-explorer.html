Voltage Divider Explorer

Two resistors, one tap. The single most-used circuit in all of electronics — every resistive sensor, every battery monitor, every level shift (converting, say, a 5 V logic signal down to a 3.3 V input) starts here. Slide V_in, R1, R2; watch V_tap, the ratio, the standby current, and the ADC count from a 12-bit converter update together.

This visual teaches the divider reflex: given V_in and a target V_out, you can pick R1 and R2 from the E12 series in seconds — and you can read off the loading limit, the standby current, and the ADC count without leaving the same chunk of math. The lesson is anchored to the fold-p4-pico battery monitor (Exercise 3 in Phase 1 — DC Circuits), so the study side and the project side reinforce each other.

How the formula falls out (KVL + Ohm)

Two resistors in series with a source, ground at the bottom, tap point between them. One closed loop, one current.

1. KVL around the loop: V_in − I·R1 − I·R2 = 0 2. Solve for I (one loop, one I): I = V_in / (R1 + R2) 3. V_tap is the voltage across R2 alone: V_tap = I · R2 4. Substitute: → V_tap = V_in · R2 / (R1 + R2)

The formula is not a separate fact; it's Ohm's law applied twice. Anytime you forget it, redo those four lines.

Picking E12 resistors for a target ratio

You usually know V_in and the V_out you want — what you need is R1 and R2 from the E12 series. The trick is to rearrange the formula so it's about ratios, not absolute values:

Start: ratio = R2 / (R1 + R2) Cross-multiply: ratio · (R1 + R2) = R2 Expand: ratio · R1 + ratio · R2 = R2 Group R2: ratio · R1 = R2 · (1 − ratio) Solve: → R2 / R1 = ratio / (1 − ratio)

Now picking is easy. For any target ratio, compute R2 / R1 as a single number; then walk the E12 series picking pairs whose ratio is closest. Try the Target V_out slider above — the panel below shows the E12 walk:

Worked example — fold-p4-pico battery monitor (Ex 3)

The constraints

1S LiPo cell on the cyberdeck: 3.0 V (cutoff) – 4.2 V (full charge). Pico 2 W ADC: 12-bit, 3.3 V reference. Map V_LiPo_max = 4.2 V to ≤ 80 % of full scale (2.64 V) so transient overshoot doesn't clip.

The arithmetic

Target ratio = 2.64 / 4.2 = 0.6286 (80 % of full scale at V_in = 4.2 V) R2 / R1 = 0.6286 / 0.3714 = 1.693 (rearranged form — look for R2 ≈ 1.7·R1) E12 pick: R1 = 33 kΩ, R2 = 56 kΩ (56/33 = 1.697 → ratio 0.6292, error 0.1 %) @ 4.2 V LiPo: V_tap = 4.2 × 0.6292 = 2.643 V (80.1 % of 3.3 V → ADC 3279/4095) @ 3.7 V nominal: V_tap = 2.328 V → ADC = 2889 @ 3.0 V cutoff: V_tap = 1.888 V → ADC = 2342 Standby current: I = 4.2 V / 89 kΩ = 47.2 µA (2000 mAh / 47 µA ≈ 4.84 years → negligible)

The firmware reconstruction

V_LiPo = adc_count · 3.3 / (4095 · 0.6292) = adc_count · 1.2810 mV/count

The project-side cheat sheet (fold-p4-pico/references/battery-math-cheatsheet.md + its HTML companion) carries these exact numbers and the battery -v TUI command that consumes them.

What to notice

  • Ratio is dimensionless, R1 + R2 sets the standby current — you can pick the ratio independently of the current draw. Bigger R1+R2 = less current = more loading; smaller R1+R2 = more current = less loading. Pick the ratio first, then scale the pair up or down to land on a current you like.
  • The R2/R1 algebra is the picking trick — converting "ratio" into a single number you compare across E12 pairs is much faster than computing V_tap for every candidate pair.
  • ADC count = V_tap / V_ref × (2^N − 1) — full scale is 1023 (10-bit), 4095 (12-bit), 65535 (16-bit). Same divider, different ADC, different number. The volts don't care.
  • Heavier loads worsen the loading effect — whatever you connect to V_tap (an ADC, an op-amp input, the gate of a FET) presents some input resistance R_load in parallel with R2. Most ADCs present 10⁴–10⁵ Ω during sampling. If R1‖R2 (= Rth, the divider's source impedance) approaches that, your reading drops. Rule of thumb: keep Rth ≤ R_load/10, ideally ≤ R_load/100.
  • The forward reference is Thévenin — once you've seen the loading effect once, you've already met Thévenin: the divider is a voltage source Vth = V_tap behind a source resistance Rth = R1‖R2. The next explorer picks up here.

Where you'll see this circuit

Real uses

  • Battery monitor — scale a cell voltage above V_ref down into the ADC's range. This explorer's worked example.
  • Resistive sensors — photoresistor, thermistor, force-sensitive resistor. One of the two resistors is the sensor; its resistance change becomes a voltage change. See voltage-dividers.md (Day 4 photoresistor circuit).
  • Level shifting — 5 V signal into a 3.3 V input. Quick and dirty (no buffering); fine for low-frequency digital lines.
  • Op-amp bias — setting a mid-rail reference for single-supply op-amps. Two equal resistors → V_ref/2.
  • Pull-up + button — a pull-up is a one-resistor divider where the second resistor is the button or device (very small when pressed, very large when open).

Cheat sheet

FORMULAS

Divider
V_tap = V_in · R2 / (R1 + R2)
Picking
R2 / R1 = ratio / (1 − ratio)
Current
I = V_in / (R1 + R2)
ADC count
N = V_tap / V_ref · (2^N_bits − 1)
Rth (loading)
Rth = R1 · R2 / (R1 + R2)
Loading factor
V_actual / V_ideal ≈ R_load / (Rth + R_load)

SHORTCUTS

  • Equal R1 = R2 → V_tap is exactly V_in / 2.
  • R2 ≫ R1 → V_tap approaches V_in.
  • R2 ≪ R1 → V_tap approaches 0.
  • Keep Rth ≤ R_load / 10 for < 10 % loading.
  • For E12 picking: R2/R1 = ratio / (1 − ratio) is the single number to compare.

COMMON PITFALLS

  • Forgetting loading — the divider only works as derived when nothing draws current from the tap. ADCs and high-Z multimeter inputs are close enough; comparators and op-amp inputs are great; a microcontroller GPIO input is fine; a logic-level FET gate (after charge) is fine; a small motor or LED is not fine.
  • Power above V_in × I — students sometimes compute V_R1·I + V_R2·I as "two powers" and double-count. The single supply delivers V_in · I total; that's the only number that matters.
  • Numerator vs denominator — the resistor in the numerator is the one you're tapping across (R2 here, the bottom one). Swapping R1 and R2 inverts the ratio.
  • Ratio drift with R tolerance — 1 % resistors give < 1 % ratio drift; 5 % carbon-film gives up to ~7 %. For battery monitors, prefer 1 % thin-film.
