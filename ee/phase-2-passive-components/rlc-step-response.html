RLC Step Response

An RLC circuit responds to a sudden step in input voltage in one of three ways: overdamped (no oscillation, slow approach), critically damped (no oscillation, fastest possible approach), or underdamped (oscillation around the target, dies out exponentially). The dividing line is the damping ratio ζ; the math is the same second-order ODE that governs car suspensions, spring-mass-dampers, control loops, and any system with two energy stores plus dissipation. This explorer lets you sweep R, L, C and watch V_C(t) directly — and gives you the precise relationship between ζ, overshoot, rise time, and settling time.

Three things to take away: (1) ζ < 1 → ringing; ζ = 1 → critical damping (no ringing, fastest); ζ > 1 → no ringing, slow; (2) overshoot is a fixed function of ζ — for a series RLC step response, OS = exp(−π·ζ / √(1−ζ²)) — so 16 % overshoot ↔ ζ = 0.5, 5 % ↔ ζ = 0.7, 1 % ↔ ζ = 0.83; (3) same ODE everywhere — every PID-controlled mechanical system, every PLL, every car suspension, every closed-loop op-amp has a second-order step response governed by this same shape.

The ODE behind the response

Series RLC driven by V_step: KVL gives V_step = L·di/dt + R·i + V_C, and i = C·dV_C/dt. Substitute i: L·C·d²V_C/dt² + R·C·dV_C/dt + V_C = V_step Divide by L·C and define ω_n² = 1/(LC), 2·ζ·ω_n = R/L: → d²V_C/dt² + 2·ζ·ω_n · dV_C/dt + ω_n²·V_C = ω_n²·V_step Solve ζ from the second relation: ζ = R/2 · √(C/L). This is the magic number that tells you everything about the response.

Worked example — series RLC current-sense damping

The setup

Inrush limiter for a 24 V supply: a series R-L-C path between rail and bulk cap. R = 1 Ω, L = 22 µH, C = 100 µF. When the supply hot-plugs at t = 0, the bulk cap charges through L; the resistor damps the LC ring. What's the inrush current waveform?

Compute ζ for series RLC

ω_n = 1/√(LC) = 1/√(22·10⁻⁶ · 100·10⁻⁶) = 1/√(2.2·10⁻⁹) = 21,320 rad/s ≈ 3.39 kHz ζ_series = R/2 · √(C/L) = 0.5 · √(100/22) = 0.5 · 2.13 = 1.07 (just over critical) Regime: slightly overdamped — no ringing on V_C; inrush current peaks ~ 45 µs after hot-plug, then decays as V_C charges (settling ~ 0.2 ms).

What if R drops to 0.1 Ω (less inrush resistor)?

ζ = 0.05 · 2.13 = 0.107 (severely underdamped) ω_d = 21,320 · √(1 − 0.0114) = 21,200 rad/s = 3.37 kHz %OS = exp(−π · 0.107 / √(1 − 0.0114))·100 = 71 % (V_C overshoots to 1.71 × V_step) t_settle ≈ 4 / (0.107 · 21,320) = 1.76 ms — long current oscillations stress the supply

For a real buck converter output (L in series, C and R_load in parallel) the damping flips: ζ_parallel = 1/(2R) · √(L/C) — heavier load (lower R) actually increases damping. With L=22 µH, C=100 µF, R_load=1 Ω that gives ζ = 0.235 (underdamped, ~47 % overshoot); dropping R to 0.1 Ω gives ζ = 2.35 (overdamped, no overshoot). See the buck-specific note in the cheat-sheet — the series formula above only applies when R, L, C are all in series.

Worked example — picking ζ for a positioning servo

The constraint

3D printer Z-axis closed-loop: ω_n is set by the mechanical resonance (lead-screw + bed mass). You can tune ζ via the velocity-loop gain (which acts as damping). What ζ do you want?

For a 3D printer, ζ = 0.7 is the sweet spot: 5 % overshoot is invisible at the print head; rise is fast; settling is quick. Going to ζ = 1 (critical) doubles the settle time. Going to ζ = 0.4 (under) gives 25 % overshoot — that's a 0.5 mm overshoot on a 2 mm move, visible as ringing on the print surface.

What to notice

  • Critical damping is the fastest response without overshoot. Overdamping is slower; underdamping has overshoot. ζ = 1 is the boundary.
  • Overshoot depends only on ζ, not on ω_n. A 16 % overshoot system at ω_n = 1 kHz looks identical (shape-wise, time-scaled) to one at ω_n = 1 MHz. Same ζ, same shape.
  • Bandwidth scales with ω_n. The closed-loop bandwidth of a 2nd-order system is roughly ω_n (for ζ near 1) up to ω_n·√(1−2ζ²+√(4ζ⁴−4ζ²+2)). Settle faster → raise ω_n (stiffer system).
  • R/L is the damping time constant. If C = 0 (just R-L), the response is a first-order exponential with τ = L/R. The 2nd-order shape only appears when both energy stores are present.
  • ESR adds free damping. A real cap has ESR; a real inductor has DCR. Both contribute to series R in the loop, which raises ζ. That's why a perfectly-modeled buck "rings less than expected" in practice — parasitic R helps.
  • The same math is everywhere. Spring-mass-damper m·ẍ + c·ẋ + k·x = F has ω_n = √(k/m), ζ = c/(2√(km)). Map: m ↔ L, c ↔ R, k ↔ 1/C, x ↔ Q, F ↔ V. Identical equation, different units.

Where you'll see this

Real uses

  • Switch-mode output filters — every buck, boost, buck-boost output LC has a step response; control loop must damp it. Note: a buck output is L in series with (C ∥ R_load), so use the parallel formula ζ = 1/(2R)·√(L/C) — heavier load is more damped, opposite of the series formula on this page.
  • PLL / Phase-locked loops — 2nd-order loop filter with damping ratio ζ chosen at 0.7 for clean phase locking.
  • Crossover networks (audio) — 2nd-order Butterworth/Linkwitz-Riley use ζ to set the −3 dB shape.
  • Closed-loop op-amp transient — when an op-amp is compensated for stability, it shows a 2nd-order step response with overshoot dictated by phase margin (which maps to ζ).
  • Motor control current loops — PI controller on a motor inductance: ζ tuned via Kp/Ki ratio.
  • Mechanical: car suspensions, MEMS accelerometers, building seismic dampers — all governed by the same equation.
  • Cross-link: Energy Storage in C and L — the two energy buckets that make the oscillation possible.

Critical V_C(t)
V_f·[1 − (1+ω_n t)·e^(−ω_n t)]

FAVORITE ζ VALUES

  • ζ = 0 → undamped (LC tank rings forever)
  • ζ = 0.2 → 53 % OS (ugly transient)
  • ζ = 0.5 → 16 % OS (fast, common in RF)
  • ζ = 0.707 → 5 % OS (Butterworth, standard)
  • ζ = 0.83 → 1 % OS (precision servos)
  • ζ = 1.0 → 0 % OS, fastest non-overshoot
  • ζ = 2 → 0 % OS, twice as slow as critical

PITFALLS

  • ζ for parallel RLC is different. Parallel: ζ = 1/(2R) · √(L/C). Series and parallel formulas are duals; check your topology.
  • Source impedance shifts ζ. A "perfect" V step from a real source has its own R_source; add it to R in the loop.
  • R can drop ESR/DCR included. Practical ζ > computed ideal ζ because of parasitic resistance.
  • Saturation breaks 2nd-order linearity. If V or I clips, the response isn't 2nd-order anymore — and you can't analyze it with this formula.
  • Higher-order systems can look 2nd-order locally but exhibit "long-tail" settling. Always sim before trusting the formula.
  • Rise time vs settling time — rise time (10–90%) is shorter than settle time (within 2 %). Don't confuse them.
