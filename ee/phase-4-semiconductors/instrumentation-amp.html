Instrumentation Amplifier (3-op-amp INA)

A precision differential amplifier with high input impedance on both inputs, gain set by one external resistor, and outstanding CMRR. The 3-op-amp topology is the workhorse for strain gauges, thermocouples, ECG/EMG biosignals, and any precision sensor read-out. This visual derives the gain, shows why CMRR is so much better than a single diff-amp, and walks the canonical strain-bridge-front-end design.

Why 3 op-amps instead of 1?

A single op-amp difference amplifier (subtracter) has two glaring problems:

  • Low input impedance. R1 in series with the +/− inputs means the source impedance directly loads the divider — typically 10 kΩ load, not the MΩ–GΩ you'd want for a strain bridge.
  • CMRR depends on resistor matching. CMRR for the diff amp = (1 + R2/R1) / (4 · ΔR/R). At 1 % resistors and gain 10, CMRR ≈ 49 dB — useless for biopotentials (60 Hz everywhere). The INA stacks gain ahead of the back-end diff amp, so CMRR scales with the front gain too.

The 3-op-amp INA solves both with two unity-gain-followers ("buffers") on each input, and the gain set by one shared R_G between the buffer outputs. The second stage is the diff amp but now it sees only the buffered + amplified signal, not the source directly. The result:

  • Input impedance > 10⁹ Ω (op-amp inputs).
  • CMRR > 90 dB from the first stage's symmetry, with the diff-amp's CMRR only adding to it.
  • Gain set by one resistor R_G, easy to change without rebalancing four-resistor diff amp.

The gain derivation (one shared current path)

Label the two inputs V1 (top) and V2 (bottom). The two unity buffers force their outputs to equal V1 and V2 respectively. R_G connects between the two buffer outputs.

1. Current through R_G: I_RG = (V1 − V2) / R_G 2. No current flows into the op-amp inputs (golden rule). So that same I_RG flows through both R_F resistors above and below. 3. Voltage at top output U1: U1 = V1 + I_RG · R_F 4. Voltage at bottom output U2: U2 = V2 − I_RG · R_F 5. Difference: U1 − U2 = (V1 − V2) + 2·R_F · (V1 − V2)/R_G = (V1 − V2)·(1 + 2·R_F/R_G) 6. Second-stage diff amp passes (U1 − U2) through with gain 1 (or sets a second gain). Final: → V_out = (V1 − V2) · (1 + 2·R_F/R_G)

Two things to notice: (1) the gain depends only on the ratio R_F/R_G, so absolute precision of R_F doesn't matter — what matters is that the two R_F resistors match each other. (2) Common-mode input V_cm = (V1+V2)/2 cancels out of (V1 − V2), so the front stage rejects CM perfectly — provided the two R_F resistors are equal.

Where CMRR comes from

The first stage rejects CM perfectly only with matched resistors. The second stage (diff amp) has CMRR limited by its 4-resistor network. INA chips like INA126 / INA826 / AD620 have laser-trimmed internal R_F resistors to < 0.01 % match. CMRR specs of 90–130 dB come from that combination of buffer-symmetry + laser-trimmed diff amp.

Try the R-mismatch slider: at 0 % mismatch, CMRR is dominated by the op-amp itself (~110 dB). At 1 % mismatch (typical thru-hole resistors), CMRR drops to ~60 dB — adequate for industrial but inadequate for biopotentials.

Worked example — strain gauge amplifier

The setup

Full-bridge strain gauges on an aluminum cantilever (gauge factor 2.1). Excitation 5 V. Maximum measurement strain ε_max = 1000 µε at full load. Differential output voltage: V_diff = V_exc × (GF × ε) = 5 × 2.1 × 1·10⁻³ = 10.5 mV at full load.

Pick the gain

Want 10.5 mV → 4.5 V at the ADC input (leaving headroom in 5 V rail). G = 4.5 / 0.0105 = 428. Note: INA126 uses a different on-chip gain formula G = 5 + 80 kΩ / R_G (not the generic 1 + 2·R_F/R_G shown in the tool above — INA126 sets its internal R_F = 40 kΩ and the back-end gain is also fixed). So R_G = 80 kΩ / (428 − 5) = 189 Ω. Closest E96: 187 Ω → actual G = 80 kΩ/187 + 5 = 433.

Why an INA

Each strain-bridge node sits at ~Vexc/2 = 2.5 V common-mode. A single-supply diff amp would not handle this CM input well (rail-to-rail input op-amp required). An INA126's CM input range (single-supply 5 V) is roughly 0.875 V to 4.125 V, so 2.5 V CM sits comfortably in the middle.

Why CMRR matters

Fractional error from common-mode = (V_cm / V_diff) / CMRR. Here V_cm/V_diff = 2.5 V / 10.5 mV ≈ 238 — the CM is 238× the signal, so CMRR must beat 238 (≈ 47 dB) just to break even. If CMRR = 80 dB (10000:1, ~1 % resistors): error = 238 / 10000 = 2.4 % of full scale — far too coarse for a real bridge. If CMRR = 60 dB (1000:1, ~5 % resistors): error = 238 / 1000 = 24 % — the CM swamps the signal. For 12-bit resolution (0.024 % LSB) you need CMRR ≥ 238 / 0.00024 ≈ 120 dB. INA126 (94 dB) gives ~0.5 % error (≈ 8-bit); an INA128 / AD8221 at ~120 dB is what makes this measurement production-grade.

Common pitfalls + design rules

  • Single-supply CM range — A standard rail-to-rail op-amp can swing inputs to either rail. But the INA's internal nodes (U1, U2) need headroom: typically V_INA must keep the internal op-amp outputs in linear range. INA126 V_CM range is roughly (V−)+0.875 V to (V+)−0.875 V (single-supply, TI SBOS062 typ). INA826 has rail-to-rail output but its inputs are limited to about (V−)+0.9 V to (V+)−1.1 V — not rail-to-rail input. Pick the right INA for your supply topology.
  • Ref pin grounding — the diff-amp stage subtracts the V_REF pin from the output. Tying V_REF to ground gives single-ended output centered on ground. Tying V_REF to Vcc/2 gives output centered on mid-rail (useful for single-supply systems feeding a bipolar ADC).
  • Bandwidth tradeoff with gain — INA gain-bandwidth limits the high-frequency response. At G=100, INA126 bandwidth is ~10 kHz. For audio or motor-current sensing at PWM frequencies, use a faster INA (AD8221, INA188).
  • EMI immunity — at high frequency, RF can rectify in the input bias transistors and bias the input offset. Use ferrite beads + 1 nF caps to ground on each input, or pick INA with built-in EMI filters (AD8232, INA821).
  • Auto-zeroing for ultra-low offset — for thermocouple / load-cell front-ends needing < 10 µV offset, use chopper-stabilized INA (e.g., LTC2057 + INA based on AD8237). Standard INA126 V_os = 250 µV is too much for sub-µV measurements.

Cheat sheet

FORMULAS

  • Gain G = 1 + 2·R_F/R_G
  • V_out = G·(V1 − V2) + V_REF
  • CMRR_total = 20·log(CMRR_1st × CMRR_2nd)
  • BW = GBW / G (gain-bandwidth limit)
  • Output noise = G·V_n_input + V_n_2nd

POPULAR INAs

  • INA126 — workhorse, 200 µA, ±2.5 V supply
  • INA826 — low-power, 200 µA, RR I/O
  • AD620 — gain 1–1000, CMRR 130 dB
  • INA188 — fast, 2 MHz BW @ G=10
  • INA826E — low-noise (8 nV/√Hz)
  • AD8221 — best CMRR (110 dB @ G=10)

PITFALLS

  • Wrong CM range — picking INA126 for single-supply 5 V means top of CM is only ~4.1 V (TI SBOS062 typ).
  • Forgetting REF pin — floating V_REF = noise + drift.
  • Gain too high — bandwidth collapses, slew limits.
  • No EMI filtering — RF rectifies in input, DC offset shifts.
  • Source impedance mismatch — even with 10⁹ Ω input, bias currents create different offsets if + and − inputs see different source impedances.
