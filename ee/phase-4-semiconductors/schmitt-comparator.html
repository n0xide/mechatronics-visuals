Schmitt Comparator (Hysteresis)

A plain comparator flips its output the instant the input crosses a single threshold — which means, in the presence of any noise, a slow-moving input causes the output to chatter rapidly around the threshold. The fix is positive feedback: feed a small fraction of the output back to the non-inverting input, so the threshold moves with the output state. The result is two thresholds — V_TH+ (the upper) and V_TH− (the lower) — and the input must move all the way from one to the other to flip the output. This hysteresis rejects noise smaller than V_TH+ − V_TH−.

Three things to take away: (1) hysteresis converts a noise-chatter problem into a noise-immunity guarantee — set the hysteresis window to be larger than the worst-case noise and the output cannot chatter; (2) the hysteresis window is set by the feedback ratio (R1/R2 in the most common configuration) and the output rail swing; (3) 74HC14 / SN74HCT14 hex Schmitt inverters give you the trick for free — 1.7 V typical hysteresis at 5 V VCC — and you'll find one in nearly every digital design that interfaces to a slow analog signal (button debounce, fan-tach, opto coupler, RS-485).

The classic non-inverting Schmitt — derivation

Configuration: op-amp / comparator with V_in to non-inverting input through R1, output fed back through R2 to the same non-inverting input. The inverting input is at a reference (often ground or V_CC/2). At the non-inverting node, V+ = V_in · R2/(R1+R2) + V_out · R1/(R1+R2) (superposition) The comparator flips when V+ = V_ref. Solve for V_in: V_in_threshold = V_ref · (R1+R2)/R2 − V_out · R1/R2 When V_out = +V_CC: V_in must drop to V_TH− for V+ to fall below V_ref → flips LOW When V_out = 0 (or −V_CC): V_in must rise to V_TH+ for V+ to exceed V_ref → flips HIGH Single-rail case with V_ref = V_CC/2 (the convention used by this tool and most single-supply Schmitt designs): V_TH+ = V_CC/2 + V_CC·β/2, V_TH− = V_CC/2 − V_CC·β/2, where β = R1/(R1+R2). Hysteresis = V_TH+ − V_TH− = V_CC·β. (For V_ref = 0 split-supply biasing: V_TH+ = V_CC·β, V_TH− = 0, hysteresis = V_CC·β — same window, shifted floor.)

Worked example — debouncing a tactile button with a 74HC14

The problem

A mechanical button hooked to a 3.3 V MCU input bounces 5–50× when pressed (mechanical contacts vibrating before settling — common chip switches show 1–5 ms of chatter). The MCU sees multiple rising/falling edges per actual press. Software debounce works but eats CPU; you can also use a 74HC14 Schmitt inverter with an RC filter to make the input clean.

The circuit

Button to ground; 10 kΩ pull-up to V_CC; 100 nF cap from input to ground; 74HC14 inverter input on the same node; output to MCU. When pressed, cap discharges through ~0.1 Ω (contact R) → fast falling edge. When released, cap charges through R = 10 kΩ → τ = 1 ms slope. The bounces happen during the fast contact, but the RC keeps the voltage on a smooth ramp that crosses each threshold only once.

The numbers

74HC14 @ 3.3 V: V_TH+ ≈ 1.8 V, V_TH− ≈ 0.9 V, hysteresis = 0.9 V (datasheet typical) RC time constant: τ = 10 kΩ · 100 nF = 1 ms (matches typical 1–5 ms bounce window) Time to cross V_TH+ on release: τ · ln(V_CC / (V_CC − V_TH+)) = 1 ms · ln(3.3/1.5) = 0.79 ms Bounces during the rise: typically 100s of µs each. Cap voltage averages to a slow ramp; only one crossing of V_TH+ → one clean rising edge into the MCU.

Why hysteresis is what makes this work

Without hysteresis, even with the RC, noise on V_CC, ground bounce, or just thermal noise can cause re-crossings near V_TH = V_CC/2. The 0.9 V gap between V_TH+ and V_TH− means any noise smaller than 900 mV peak-to-peak cannot cause a re-trigger. Hysteresis is what turns "RC filter" into "RC filter that actually works."

Worked example — designing a thermostat with ±2 °C hysteresis

The setup

A 10 kΩ NTC thermistor in a voltage divider against a 10 kΩ pull-up to 5 V produces a temperature-dependent voltage at the divider node. You want a relay turn-on at 20 °C (cold) and turn-off at 22 °C (warm) — 2 °C of hysteresis so the relay doesn't chatter when temperature drifts near the setpoint.

The arithmetic

At 20 °C, NTC ≈ 12.5 kΩ → V_div = 5 · 12.5 / 22.5 = 2.78 V (rising threshold) At 22 °C, NTC ≈ 11.6 kΩ → V_div = 5 · 11.6 / 21.6 = 2.69 V (falling threshold) Required hysteresis window: 2.78 − 2.69 = 90 mV (needs about ±45 mV around V_ref = 2.74 V) Comparator output swings 0 – 5 V. Pick feedback ratio: ΔV_TH = V_CC · R1/(R1+R2) 0.09 = 5 · R1/(R1+R2) → R1/(R1+R2) = 0.018 → R2/R1 = 54.5 Pick R1 = 10 kΩ → R2 = 545 kΩ → use E12 560 kΩ (nearest). Resulting hysteresis = 5 · 10/570 = 87.7 mV ✓

The result

The relay turns on at 20 °C, runs the heater, and won't turn off until the temperature rises to 22 °C — even if intermittent drafts cool the sensor briefly. The hysteresis ensures one switch per 2 °C cycle. Bonus: using a microcontroller ADC + software comparator, you get this hysteresis essentially free in code — but for a $0.30 LM393 comparator + two resistors, you don't need a microcontroller at all.

What to notice

  • Drag V_in slowly through the threshold region with noise > 0. Without hysteresis (R2 large), the output would chatter wildly. With hysteresis, the output snaps once and stays.
  • Wider hysteresis = more noise immunity but slower threshold response. The signal must move further to flip the output. There's a fundamental trade between sensitivity and noise rejection.
  • Output rail swing affects hysteresis. If V_out = ±15 V instead of 0–5 V, the hysteresis is 6× wider for the same R1, R2. A rail-to-rail comparator's hysteresis is bigger than a non-rail-to-rail one with the same feedback network.
  • The 74HC14 hex Schmitt inverter bakes hysteresis into a single chip. Six inverters per package; ~1.7 V hysteresis at 5 V VCC. The fastest, cheapest way to add hysteresis without designing the feedback network yourself.
  • Schmitt = positive feedback. Any feedback from output to non-inverting input is positive feedback — destabilizing. Comparators welcome this; linear amplifiers must avoid it (it makes them oscillate).
  • The inverting and non-inverting topologies have different formulas. The non-inverting Schmitt is V_TH = V_CC·R1/(R1+R2); the inverting Schmitt centers on V_ref ± V_CC·R1/(R1+R2). Pick the one whose input polarity matches your sensor.

Where you'll see this

Real uses

  • Button / switch debounce — 74HC14 + RC = clean digital edge from any mechanical contact.
  • Optical encoder receivers — phototransistors give noisy slow edges; Schmitt cleans them up.
  • RS-485 / CAN receivers — differential receivers (SN65HVD230, MAX485) have built-in ±200 mV hysteresis.
  • UART / I²C bus monitors — same idea; slow rise times need hysteresis.
  • Battery low-voltage cutoff — turn off the load at 3.0 V, turn back on at 3.4 V to avoid oscillation near the threshold.
  • Relaxation oscillators (555 timer) — the 555 internally has a Schmitt that oscillates an RC charge/discharge between 1/3 V_CC and 2/3 V_CC.
  • Logic-level translators — converting noisy 1.8 V signals to clean 3.3 V CMOS uses Schmitt-input translators.
  • Cross-link: Instrumentation Amp — when you need to amplify, not compare.

Cheat sheet

FORMULAS

V_TH+ (non-inv)
= V_ref · (R1+R2)/R2 + V_OL · R1/R2
V_TH− (non-inv)
= V_ref · (R1+R2)/R2 + V_OH · R1/R2
Single-rail simple
V_TH+ = V_CC · R1/(R1+R2), V_TH− = 0
Hysteresis
ΔV = (V_OH − V_OL) · R1/(R1+R2)
Feedback ratio β
β = R1/(R1+R2)
74HC14 typ @ 5V
V_TH+ ≈ 2.7V, V_TH− ≈ 1.0V → ΔV ≈ 1.7V

WHEN TO USE

  • Slow-moving input crossing a threshold.
  • Input has noise larger than threshold uncertainty.
  • You need a clean digital edge from a slow analog signal.
  • Avoiding output chatter from a relay/contactor.
  • Battery-level cutoff with hysteresis to prevent restart cycling.
  • RC oscillators (555 timer, Schmitt-trigger oscillator).

PITFALLS

  • Forgetting the comparator vs op-amp distinction. Op-amps used as comparators are slow and may latch up. Use a real comparator (LM393, LM339, MAX942, TLV3501).
  • Open-collector vs push-pull output. LM339 is open-collector — needs a pull-up. Output rail = V_pull-up, which matters for hysteresis.
  • Sourcing/sinking limits. Feedback resistor draws current from the output; size large enough to not load it.
  • Comparator slew rate. A slow comparator (LM393, ~1.3 µs prop) won't help with fast input transitions. Use TLV3501 (4 ns) for fast.
  • Power-supply noise on V_ref. V_TH+ depends on V_ref. Bypass V_ref with a cap.
  • Open-loop oscillation in a non-Schmitt comparator. Without hysteresis, slow inputs cause chatter. Hysteresis is mandatory if input edges are slower than the comparator's prop delay.
