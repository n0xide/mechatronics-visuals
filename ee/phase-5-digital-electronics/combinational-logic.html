Combinational Logic

Half/full adders, ripple-carry chains, multiplexers, decoders, and priority encoders — the building blocks of every ALU and bus controller.

Combinational logic means no memory — outputs are pure functions of current inputs. Each tab below isolates one canonical block. Toggle the inputs and watch how signals propagate. The ripple-carry tab also shows the delay penalty that motivates carry-lookahead and prefix adders in real CPUs.

What to notice

  • Full adder = half adder + half adder + OR — once you see the structure, the carry-out formula becomes obvious.
  • Ripple-carry delay is linear in N — a 64-bit ripple adder is unusable in a CPU. Carry-lookahead adders compute carries in parallel; Brent-Kung/Kogge-Stone scale as O(log N).
  • The MUX is "if-then-else" in silicon — every conditional branch in a hardware datapath is a mux selecting between alternatives.
  • Decoder enables exactly one output, so it is the canonical address-line driver — assert the right column or row.
  • Priority encoder needs the "valid" output — otherwise output 000 ambiguously means "I0 is active" or "no inputs active."

MEMORIZE

  • MUX = if/else in hardware — S selects A or B.
  • Decoder = case statement — exactly one output HIGH.
  • XOR = inequality, XNOR = equality detector.

COMMON PITFALLS

  • Ripple-carry delay — N-bit adder takes ~N gate delays; use CLA for wide adders.
  • Decoder enable — without EN, decoder is always active; can clash on a bus.
  • Priority encoder ambiguity — 000 means "I0 active" AND "all zero"; always emit a valid flag.
