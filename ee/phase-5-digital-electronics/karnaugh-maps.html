Karnaugh Maps

Click cells to set 0 / 1 / X (don't care). The tool auto-groups powers of 2 and reads off the minimized SOP or POS expression. Gray-code adjacency is visible in the row/column labels.

A K-map is a 2D rearrangement of the truth table where physically adjacent cells differ by exactly one variable (Gray code). That means any group of adjacent 1s — of size 1, 2, 4, 8, or 16 — collapses into a product term with one variable eliminated per doubling. Wrap-around counts: the top edge is adjacent to the bottom, the left to the right.

What to notice

  • Gray code on the labels — 00, 01, 11, 10 (not 00, 01, 10, 11). Adjacent cells must differ by one bit so that doubling a group eliminates exactly one variable.
  • Wrap-around groups are legal — top edge ↔ bottom edge, left ↔ right. The map is topologically a torus.
  • Group sizes are powers of 2 only — 1, 2, 4, 8, 16. Each doubling removes one literal from the term.
  • Don't-cares are free literals — set them to 1 if they enlarge a 1-group, to 0 if they enlarge a 0-group. The minimizer here makes that choice automatically.
  • SOP vs POS picks whichever is shorter — if F is mostly 1s, group the few 0s and write POS; if mostly 0s, group the 1s as SOP.

Cheat sheet

GROUPING RULES

  • Size = 2ᵏ — only 1, 2, 4, 8, 16 cells.
  • Rectangles only — no L-shapes or diagonals.
  • Wrap edges — top↔bottom, left↔right are adjacent.
  • Overlap OK — cells can belong to multiple groups.
  • Biggest first — larger group = fewer variables.

GRAY-CODE ORDER

2-var
columns: 0,1; rows: 0,1
3-var
cols: 00,01,11,10
4-var
cols and rows: 00,01,11,10

COMMON PITFALLS

  • Forgetting wrap — corners of 4-var K-map are all adjacent.
  • Missing don't-cares — X cells can enlarge a group for free.
  • Non-essential prime implicants — covering with too many groups bloats the SOP.
  • Hazards — minimal SOP can glitch on input transitions; add redundant terms.
