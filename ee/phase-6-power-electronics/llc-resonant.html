LLC Resonant Converter — soft-switching for 95-97% efficiency

The LLC is the workhorse for server PSUs, EV chargers, and high-end audio amps in the 100 W to 3 kW range. Two resonant elements (L_r + C_r) make a series tank, a parallel magnetizing inductance L_m provides voltage regulation through frequency. The trick: tank impedance lets the MOSFETs switch at zero voltage (ZVS), eliminating turn-on loss. Efficiencies 95-97 % at full load are standard. This visual shows the gain curve M(F_n), the three operating regions, and what tilts the curve as L_m/L_r changes.

f_r1 = 1 / (2π√(L_r·C_r)) — series resonance f_r2 = 1 / (2π√((L_r+L_m)·C_r)) — second resonance k = L_m / L_r (typ 4-7) Q = √(L_r/C_r) / R_ac — load Q ZVS at f_sw > f_r1; ZCS impossible at high Q Gain M = V_out / (V_in/2N) — 0.5 to 1.5 typical

The gain equation

Using First-Harmonic Approximation (FHA), the tank looks like a series-parallel network: V_out · 2N / V_in = |M(F_n, k, Q)| M(F_n, k, Q) = 1 / √( ( (1 + 1/k − 1/(k·F_n²))² + Q²·(F_n − 1/F_n)² ) ) F_n = f_sw / f_r1 normalized frequency k = L_m / L_r inductance ratio (typically 4-7) Q = √(L_r/C_r) / R_ac loaded quality factor R_ac = 8·N² / π² · R_load reflected load (FHA approximation) Key frequencies: f_r1 = 1 / (2π·√(L_r·C_r)) series resonance — gain = 1 always f_r2 = 1 / (2π·√((L_r + L_m)·C_r)) second resonance — gain peak at no-load Three operating regions: f_sw > f_r1 : ZVS, M < 1 (buck-mode), input impedance inductive ✓ preferred region f_sw = f_r1 : unity gain regardless of load (the magic point) f_r2 < f_sw < f_r1 : ZVS, M > 1 (boost-mode), still safe f_sw < f_r2 : ZCS region — body-diode hard switching; AVOID (kills efficiency + EMI)

Tank design — picking L_r, L_m, C_r

Step 1: pick f_r1 from EMI + magnetics

Higher f_r1 = smaller magnetics + faster transient response, but higher gate-drive + core loss. Typical:

  • 100-150 kHz: standard server PSUs, ferrite cores, MOSFETs work cheap
  • 200-300 kHz: high-density chargers, planar transformers
  • 400-1000 kHz: GaN-based, integrated-magnetics designs

Step 2: pick k = L_m / L_r

k = 4-7 typical. Smaller k → wider gain range (better at handling V_in transients), but more magnetizing current and worse light-load efficiency. Larger k → narrower gain range (works only near f_r1) but better efficiency.

Step 3: pick Q from load Q tables

Q_max at full load is usually 0.3-0.6. The "peak gain" of the curve must exceed the max required gain at min V_in, with margin. Standard LLC design tables (Yang 2003, Lee 2010) give the relationship between k, Q_max, and required M_max.

Step 4: solve for L_r, L_m, C_r

Given f_r1, k, Q_max, R_ac at full load:

L_r = Q · R_ac / (2π · f_r1) C_r = 1 / (2π · f_r1)² / L_r L_m = k · L_r

Worked example — 240 W server PSU rectifier (12 V output from 400 V bus)

Specs

Server PSU: 400 V DC bus → 12 V / 20 A = 240 W output. Target η ≥ 96 %. Pick f_r1 = 100 kHz, k = 5.7, Q_max = 0.4 at full load.

Compute reflected load

N = N_p / N_s. For LLC at unity gain, V_out = V_in / (2N) → N = V_in/(2·V_out) = 400/24 = 16.67. Pick N = 16. R_load = 12² / 240 = 0.6 Ω R_ac = (8/π²) · N² · R_load = 0.811 · 256 · 0.6 = 124.5 Ω

Resonant tank

L_r = Q·R_ac / (2π·f_r1) = 0.4 · 124.5 / (2π · 100e3) = 79.3 µH → use 75 µH C_r = 1 / ((2π·100e3)² · 75e-6) = 33.8 nF → use 33 nF C0G ceramic f_r1_actual = 1/(2π·√(75e-6·33e-9)) = 101.1 kHz ✓ L_m = k·L_r = 5.7 · 75 = 427 µH → integrated into transformer

Verify operating range

f_r2 = 1/(2π·√((75 µH + 427 µH) · 33 nF)) = 1/(2π·√(502 µH · 33 nF)) = 39.1 kHz Operating: f_sw = 100 kHz (right at f_r1) at nominal → M = 1 exactly Low-line (350V): F_n drops to ~0.85 → M rises to ~1.14 → V_out stays at 12 V ✓ No-load: F_n rises to ~1.3 (M drops); controller skips pulses below 30 % load

Controller: TI UCC256301 or NXP MC56F LLC. Synchronous rectifier on secondary picks up the remaining 1-2 % efficiency.

Where things go wrong

  • Falling into ZCS region (f_sw < f_r2) — at no-load + low V_in, the controller may push frequency way down. Body diodes hard-switch, ringing destroys MOSFETs. Always include a min-frequency clamp.
  • Magnetizing-current sizing too small — L_m needs enough magnetizing current to charge C_oss of the MOSFETs during dead time for ZVS. Rule: I_mag(peak) ≥ V_in · C_oss / t_dead.
  • Light-load efficiency cliff — at < 20 % load, magnetizing-current loss dominates. Use burst-mode controller (skip-pulse) to reduce f_eff at light load.
  • Tolerance stack — L_r tolerance ±10 %, C_r ±5 % means f_r1 has ±7-8 % variation. Design margin into the gain curve, especially at the gain peak.
  • Transformer leakage IS L_r — modern designs use the transformer's leakage inductance as L_r (no external inductor). Tightly controlled by transformer construction; "integrated magnetics".
  • Forgetting body diode reverse recovery — at high Q + load step, secondary diode reverse-recovery currents flow back through the resonant tank and cause oscillation. Use SiC diodes or synchronous MOSFETs.
  • FHA approximation breaks at high gain — actual peak gain is ~10-15 % below what FHA predicts. Production design uses time-domain simulation (PSIM, LTspice) or vendor tools (TI Power Designer) for accuracy.
