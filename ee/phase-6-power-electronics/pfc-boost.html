PFC Boost Converter — shaping input current to look resistive

A diode-bridge + bulk-cap front-end on AC mains draws current only at the peaks of the voltage waveform, creating massive harmonic distortion and a poor power factor. A Power Factor Correction (PFC) boost converter sits between the bridge and the bulk cap, forcing the input current to track the input voltage sinusoidally. The output is a regulated DC rail (typically 380–400 V); the input current is a clean low-distortion sine in phase with mains voltage. Required by EN-61000-3-2 in Europe for any device above ~75 W.

Why PFC is required

An uncompensated bridge + cap (common for cheap AC adapters < 75W) draws current in a narrow pulse near the peak of each AC half-cycle — the cap recharges briefly when input voltage exceeds the cap's voltage. Result:

  • Power factor ~0.5 — utility delivers 2× the apparent power needed for the real load.
  • Harmonic distortion > 80 % — current waveform has huge 3rd, 5th, 7th harmonics that propagate up the distribution feeder, causing transformer heating and resonance with grid-side caps.
  • Inrush problem — at turn-on, cap is empty, full mains current rushes in. Limited only by trace + diode resistance.

How the PFC boost achieves PF ≈ 1

1. After bridge, V_rectified = |V_in| (full-wave rectified sinusoid) 2. PFC boost steps it up to constant V_out (380-400 V). 3. Inductor current I_L is controlled to follow |V_in| · k(t), where k(t) is a slowly-varying constant set to deliver the required power. 4. Because I_L tracks |V_in|, the input current looks like a clean rectified sinusoid in phase with V_in. 5. Behind the bridge, the AC source sees current = sin(ωt) · k — pure sinusoid in phase with voltage. PF = 1.

Three modes of operation

  • CCM (Continuous Conduction Mode) — inductor current never drops to zero. Smaller current ripple, larger inductor. Best for >200 W. Requires average-current-mode control.
  • CrM / BCM (Boundary / Critical Conduction Mode) — inductor current reaches zero at the start of each switching cycle. No inductor stored energy at switch-on (zero-current switching = lower switching loss). Smaller inductor. Best for 50–200 W. Variable switching frequency, locks to "next-zero-crossing-of-inductor-current".
  • DCM (Discontinuous) — inductor empties before next cycle starts; current pulses with dead time. Easier to control but high RMS currents, mostly for <100 W.

Pitfalls

  • Light-load efficiency — at 5 % load, PFC's switching losses dominate. Modern controllers offer burst mode or skip cycles.
  • Output voltage bandwidth loop — voltage loop must be slow (10-20 Hz) to not modulate the input current. Setting bandwidth too high creates 2nd-harmonic input distortion.
  • Inrush limiting — at turn-on, output cap is empty. Use NTC inrush limiter or active relay-bypass with pre-charge resistor.
  • Brownout — if V_in droops mid-cycle, output sags. Need adequate output cap + brown-out detection.
  • Diode reverse recovery — at the high switching frequency + high voltage, Q_rr matters. Use SiC Schottky for 600 V class.

Efficiency breakdown

MOSFET conduction (peak-based worst case): I_peak² · R_DS(on) · D = 13.3² × 0.025 × 0.70 ≈ 3.1 W. The RMS-based form (≈ I_peak²·R·D/2 ≈ 1.5 W) gives the real efficiency number; use the worst case for thermal sizing.
MOSFET switching: ½·V·I·f·(t_on+t_off) ≈ ½·400·13·1e5·30e-9 = 7.8 W
Diode: V_f · I_avg = 1.5 × 2 = 3.0 W
Inductor copper loss: I² · DCR = 9.4² × 0.05 Ω = 4.4 W
Total loss: ~20 W → η = 800/(800+20) = 97.5 % ✓

Bridgeless PFC — the next step

A diode bridge at the AC input is the largest loss in a classic PFC topology (4 diode drops × I_rms = ~3 W at 8 A). Bridgeless PFC eliminates the bridge by using two boost inductors and four MOSFETs configured as a totem-pole structure. The MOSFETs handle both the rectification and the boost switching, dropping V_f losses to near zero.

  • Totem-pole PFC — most common bridgeless variant. Two MOSFETs in series across the bus + two low-frequency MOSFETs for rectification. Achievable: 98%+ efficiency.
  • Requires fast-switching low-Q_rr devices — SiC or GaN. Si MOSFETs body-diode Q_rr ruins efficiency.
  • Modern data-center PSU standard — Open Rack v3 and 80-PLUS Titanium spec require 96%+ efficiency at 50 % load. Bridgeless totem-pole + SiC is the recipe.
