I2C Protocol

Two open-drain wires, one master clock, ACK every byte. Watch a complete write transaction and size pull-ups for your bus.

I2C is the multi-drop bus you reach for when you have many slow peripherals. Both lines (SDA, SCL) are open-drain — devices only pull LOW, never drive HIGH; the pull-up resistor restores HIGH. That's how arbitration and ACK work: SDA is a wired-AND across all participants.

Full transaction: START → addr+R/W → ACK → data → ACK → STOP

Pull-up resistor sizing

Open-drain means rise time is set by R·C — the pull-up charging the bus capacitance. Too large R → slow rise → missed clocks at higher speeds. Too small → device can't sink enough current to pull LOW (I2C spec limits sink to ~3 mA).

SDA rise time for chosen R

t_rise (30%→70%, per I²C spec) ≈ 0.8473 · R · C_bus   ·   R_max = t_rise_spec / (0.8473 · C_bus)   ·   R_min = (V_cc − V_OL_max) / I_OL_max ≈ (V_cc − 0.4) / 3mA

What to notice

  • START / STOP are SDA edges while SCL is HIGH — every other SDA transition must happen while SCL is LOW. This is what tells receivers "framing event" vs "data bit".
  • Address + R/W̄ is one byte (7-bit mode) — 7-bit address shifted left by 1, with R/W̄ in bit 0. So address 0x50 with write becomes 0xA0 on the wire. 10-bit addressing exists too: first byte is 11110AAW (the 11110 prefix flags a 10-bit address, AA are the two MSBs of the 10-bit address, W is R/W̄), followed by a second byte carrying the lower 8 bits. Almost all I²C parts use 7-bit; 10-bit is rare.
  • ACK is the slave pulling SDA LOW — master releases SDA after the 8th data bit; if the addressed slave is present and ready, it sinks SDA LOW during the 9th clock. No slave = SDA stays HIGH = NACK.
  • Pull-up is a band of acceptable values — bounded above by rise-time spec (RC charge), below by sink-current spec. Higher speed → tighter window → smaller R.
  • Open-drain lets devices share the bus — no driver conflicts: pulling LOW always wins, releasing lets the pull-up restore HIGH. Multi-master arbitration uses this same property on SDA.

Cheat sheet

MEMORIZE

  • Open-drain + pull-ups on both SDA and SCL — mandatory.
  • Speeds — 100k standard, 400k fast, 1M fast+, 3.4M HS.
  • ACK — slave pulls SDA LOW on 9th clock.
  • Address — 7-bit shifted left + R/W̄ bit (0x50 → 0xA0/0xA1).

COMMON PITFALLS

  • Address conflicts — fixed-address parts collide; add TCA9548A mux.
  • Missing pull-ups — bus floats, NACK everywhere.
  • Long cable — C_bus blows rise-time; drop speed or use buffer (PCA9517).
  • Clock stretching — slow slaves hold SCL LOW; some MCUs don't honor.
