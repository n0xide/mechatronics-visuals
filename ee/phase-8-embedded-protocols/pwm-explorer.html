PWM Explorer

Pulse-width modulation: a square wave whose duty cycle encodes an analog level. Slide the duty to see V_avg track linearly; compare fast vs phase-correct counting modes.

PWM is how MCUs make analog magic from a digital pin. A timer counts up to TOP at a fixed frequency, comparing each count to a register; the pin is HIGH when count < register, LOW otherwise. The fraction of time HIGH is the duty cycle, and a downstream filter (RC, an LED's persistence-of-vision, or a motor's inductance) does the averaging.

Fast PWM vs phase-correct PWM

Fast PWM: counter ramps 0→TOP→0, pin asserts at count=0, deasserts at count=COMPARE. Edges always align at t=0. Phase-correct: counter ramps 0→TOP→0 then TOP→0; pulses are centered, so two channels with different duties share the same center. Phase-correct halves the effective frequency (f = f_clk/(2·TOP) instead of f_clk/(TOP+1)) but produces less harmonic content; preferred for motor drive.

What to notice

  • V_avg is exactly D · V_supply — for any duty, any frequency. The downstream filter just decides how much ripple rides on top.
  • Resolution is steps, not volts — 8-bit PWM on 3.3 V gives 256 levels of ~13 mV each. To get more levels you need more counter bits, but at the cost of timer frequency.
  • f × 2^N = timer clock — to keep N bits of resolution at frequency f, the timer hardware must run at least at f·2^N. 16-bit PWM at 25 kHz needs 1.6 GHz of timer clock — impossible on most MCUs; trade resolution for frequency.
  • Fast vs phase-correct halves f — phase-correct counts both up and down, so one period takes 2·TOP ticks. Use phase-correct when phase alignment between channels matters (H-bridge, three-phase motor).
  • Software PWM is jittery — CPU servicing interrupt has variable latency. Hardware PWM runs from the timer peripheral and is precise to one timer clock.

MEMORIZE — frequency picks

  • > 1 kHz — LED backlight, no visible flicker.
  • > 20 kHz — motors, above audible whine.
  • 50 Hz — RC servos (1–2 ms pulse).
  • Phase-correct — H-bridge, 3-phase motor.

COMMON PITFALLS

  • Software PWM jitter — ISR latency varies; use hardware timer channel.
  • No deadtime — H-bridge shoot-through when both FETs briefly conduct.
  • Audible whine — pick f above 20 kHz for motor drives.
  • Resolution vs frequency — both fight for timer clock budget.
