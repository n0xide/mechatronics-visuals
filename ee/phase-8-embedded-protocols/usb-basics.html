USB Basics

USB hangs everything off a four-level descriptor tree. Click around the tree, watch NRZI encoding scramble a bit pattern onto D+/D−, and compare classes by bandwidth and latency.

A USB device is described by a fixed hierarchy: one Device, with one or more Configurations, each containing one or more Interfaces, each with one or more Endpoints. The host enumerates this tree at plug-in time to decide which driver to load.

NRZI encoding on D+/D−

USB does not send bits directly — it uses Non-Return-to-Zero Inverted: a "0" causes the line to toggle, a "1" keeps it the same. After 6 consecutive ones, the transmitter inserts a stuffed "0" to guarantee transitions for clock recovery. The pair D+/D− carries differential data; J-state and K-state are the two valid signaling states.

What to notice

  • Endpoints, not interfaces, carry data — every byte flows through an endpoint; interfaces just group endpoints by purpose. EP0 is always control; EPs 1–15 are direction-paired (IN/OUT separate).
  • HID = poll-based, CDC = stream-based — HID gives a guaranteed slot every N ms but tiny payloads; CDC gets bulk endpoints with no timing guarantee but high throughput.
  • NRZI ensures transitions — under NRZI, "0" toggles the line and "1" holds it, so long runs of 1s would starve the receiver clock of edges. Bit stuffing inserts a "0" after 6 consecutive 1s. (Runs of 0s already transition every bit and are not stuffed.)
  • Default power is 100 mA — until enumeration completes you cannot draw more. Devices that boot >100 mA fail on some hosts. Request 500 mA in the configuration descriptor and stay under it before SET_CONFIGURATION.
  • Isochronous has no retry — used for audio/video where late data is useless. CRC errors drop the packet; codec deals with the gap.

Cheat sheet

MEMORIZE

  • Wires — D+ / D− differential, 90 Ω characteristic.
  • Speeds — LS 1.5M / FS 12M / HS 480M / SS 5G bps.
  • Classes — HID = no driver, CDC = virtual COM, MSC = storage.
  • Power — 100 mA default, 500 mA configured, 900 mA USB 3.

CLASS DECISION

  • HID — keyboard, mouse, gamepad (low rate, no driver).
  • CDC — serial-over-USB (Arduino, modems).
  • MSC — flash drive, SD-card reader.
  • Audio / Video — UAC, UVC (isochronous, no retry).

COMMON PITFALLS

  • Slow enumeration — host expects descriptors within ms; blocking init fails detect.
  • No USB on MCU — need CH340 / CP2102 / FT232 bridge for plain UART parts.
  • Power draw before SET_CONFIG — must stay under 100 mA.
