Field-Weakening — Running BLDC above base speed

A BLDC motor's back-EMF rises linearly with speed. At "base speed" the back-EMF equals the available bus voltage minus IR drop — beyond that point you cannot increase current to make more torque, because there's no voltage headroom left. Field-weakening injects negative d-axis current (I_d < 0) that opposes rotor flux, reducing effective back-EMF and giving back voltage headroom for q-axis (torque) current. Speed can be extended 2-3× past base; max torque drops in proportion. This is how EVs and e-bikes reach high cruising speed despite a fixed battery voltage.

The math behind field-weakening

Voltage equations in dq frame (steady state, ignoring R first): V_d = −ω · L_q · I_q V_q = +ω · L_d · I_d + ω · ψ_pm (ψ_pm = K_e is the rotor-magnet flux linkage) Voltage limit (bus): V_d² + V_q² ≤ (V_bus/√3)² for a 3-phase inverter Below base speed: I_d = 0, V_q = ω·ψ_pm grows with speed. At ω_base = V_bus/(√3·ψ_pm), V_q reaches the limit. Above base speed: force I_d < 0 so V_q = ω·(ψ_pm + L_d·I_d) stays bounded. Required I_d (rough formula): I_d ≈ (V_bus/(√3·ω) − ψ_pm) / L_d  (must be ≤ 0) Then I_q is limited by total current: I_q ≤ √(I_max² − I_d²)

Why this matters for EV / e-bike / drone designs

The use case

An electric car has a fixed battery voltage (say 400 V). At low speeds, the motor needs torque (acceleration), so it draws I_q up to the thermal limit. At highway speeds, the back-EMF approaches battery voltage — no headroom for current. Without field-weakening, top speed is limited by V_bus / K_e.

Field-weakening lets the same motor run 2-3× faster while making less torque. The car's constant-power region (where it cruises easily but can't accelerate hard) is created entirely by this technique.

The trade-offs

  • Higher copper loss at the same torque — you're carrying I_d for no torque benefit.
  • De-magnetization risk at high I_d in PM motors — magnets can demagnetize if I_d is too large. Track magnet temperature.
  • Voltage utilization jumps from 90% (pre-weakening) to ~95-98% — requires precise SVPWM + accurate current sensing.
  • Sensorless schemes fail in deep field-weakening because back-EMF is suppressed by design.

Worked example — Tesla Model 3 traction motor

The motor

3-phase permanent-magnet synchronous motor (PMSM), 6-pole-pair, ψ_pm = K_e ≈ 0.08 V·s/rad (rotor flux linkage, phase peak), L_d ≈ 200 µH, peak current 1000 A. Battery: 350 V DC nominal.

Base speed

ω_base = V_bus / (√3 · ψ_pm) = 350 / (1.732 · 0.08) = 2530 rad/s In RPM: 2530 · 60 / (2π) = 24,160 RPM electrical = 24,160 / 6 = 4030 RPM mechanical Wheel RPM at 4030 motor RPM with 9:1 ratio + 0.65m wheel = 4030/9 × π × 0.65 × 60/1000 = 55 km/h

Field-weakening kicks in at 55 km/h

Above 55 km/h, motor enters constant-power region. Max torque drops as 1/speed. At 110 km/h (2× base), torque is halved but power stays the same. At 200 km/h, torque is ~28% of max, power still ~constant. The "thinning" of acceleration above 100 km/h is exactly this curve.

Above ω_max (~3× base, ~165 km/h), the inverter cannot weaken more — power starts to drop. This sets the absolute top speed.

Implementation in FOC

How the controller computes I_d_ref

In FOC, the speed/position loop outputs a torque demand. The MTPA (Maximum Torque Per Ampere) or MTPV (Maximum Torque Per Voltage) optimization decides how to split I_q + I_d.

  • MTPA: at low speed, use I_d = 0 (all current as I_q) — gives max torque for min losses
  • Voltage-feedforward field-weak: as ω increases, compute required I_d from V_bus headroom. Apply negative.
  • Voltage-feedback field-weak: monitor V_q magnitude; if it nears bus limit, increase |I_d|. Closed-loop, robust to parameter mismatch.
  • I_d limit: |I_d| capped at the demagnetization current of the magnets (typically 50-70% of I_max).

Modern FOC libraries (TI MotorWare, ST X-CUBE-MCSDK, ODrive) implement voltage-feedback field-weak by default. Manual tuning rarely needed.

Common pitfalls

  • Forgetting the R drop — at high current, the IR drop subtracts from voltage budget. Real ω_base is lower than the no-R formula.
  • Saturation of L_d at high I_d — magnetic saturation reduces inductance, increasing required I_d for the same back-EMF reduction. Use saturation-aware lookup tables in production code.
  • Magnet demagnetization — at high I_d AND high temperature, magnets lose remanence permanently. Track magnet temp + cap I_d accordingly.
  • Loss of control at very high speed — if MCU cannot run fast enough to maintain stable FOC at 100 kHz+ electrical frequency, system saturates and torque vanishes.
  • EMI pickup on current sensors at high field-weakening current — sensor noise looks like real I_d, controller diverges.
