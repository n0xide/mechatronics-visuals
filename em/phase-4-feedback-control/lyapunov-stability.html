Lyapunov Stability — proving "this nonlinear thing won't blow up"

Linear systems give you eigenvalues: if all real parts are negative, you're stable. For nonlinear systems — pendulums, friction, saturating actuators, anything with terms like sin(θ) or x·y — eigenvalues only describe behavior near one operating point. Lyapunov's method finds a scalar "energy-like" function V(x) of the state. If V is positive everywhere except the origin, and V decreases along every trajectory, the system is stable. No need to solve the equations of motion. This visual builds V for three example systems, plots the trajectory + level sets, and marks where V̇ flips sign.

The Lyapunov stability theorems

Given autonomous system ẋ = f(x), f(0) = 0 (origin is the equilibrium). A function V : ℝⁿ → ℝ is a Lyapunov function candidate if: • V(0) = 0 • V(x) > 0 for all x ≠ 0 in some neighborhood (positive definite) • V is continuously differentiable Compute the derivative along trajectories: V̇(x) = ∇V(x) · f(x) (gradient of V dotted with the vector field) Theorem (Lyapunov): V̇(x) ≤ 0 in a neighborhood ⇒ origin is stable (Lyapunov stable) V̇(x) < 0 in a neighborhood (x ≠ 0) ⇒ origin is asymptotically stable V̇(x) > 0 somewhere ⇒ test fails (might still be stable — V is just the wrong candidate) LaSalle's invariance principle: if V̇ ≤ 0 and the largest invariant set inside {x : V̇ = 0} is just {0}, then the origin is asymptotically stable even though V̇ has zero crossings. Region of attraction: the largest sublevel set {x : V(x) ≤ c} contained in the region where V̇ < 0 estimates how far from the origin you can start and still converge.

Three worked systems

1. Mass-spring-damper (LTI, easy case)

ẋ = v, v̇ = −(k/m)x − (b/m)v Candidate: V(x, v) = ½kx² + ½mv² (total stored energy) V̇ = kx·ẋ + mv·v̇ = kxv − kxv − bv² = −bv² V̇ ≤ 0 always; V̇ = 0 only when v = 0 (then by LaSalle, also x = 0 eventually). ⇒ asymptotically stable for any b > 0, regardless of how large the initial energy is. Global!

2. Damped pendulum (nonlinear, can swing past upright)

θ̈ = −(g/L)·sin(θ) − (b/(mL²))·θ̇ Candidate: V(θ, θ̇) = mgL(1 − cos θ) + ½mL²θ̇² (PE + KE) V̇ = mgL·sin(θ)·θ̇ + mL²θ̇·θ̈ = mgL·sin(θ)·θ̇ − mgL·sin(θ)·θ̇ − b·θ̇² = −b·θ̇² V̇ ≤ 0; LaSalle gives asymp. stability of the downward equilibrium. Region of attraction bounded by V < 2mgL (energy below the "over-the-top" threshold). Start with too much energy ⇒ pendulum loops over the top, then settles. Not asymptotically stable to θ=0 globally; only inside the "first cup" of the energy landscape.

3. Van der Pol (unstable origin, stable limit cycle)

ẋ = v, v̇ = µ(1 − x²)v − k·x (µ > 0; k = 1 for the canonical Van der Pol) Try V = ½k·x² + ½v² (kinetic + spring energy, with the matching k from the dynamics): V̇ = k·xv + v[µ(1−x²)v − k·x] = µ(1 − x²)v². The k·xv from ∂V/∂x and the −k·xv from v·v̇ cancel exactly because V's stiffness matches the spring constant in v̇ — works for any k > 0. (If you tried V = ½x² + ½v² with k ≠ 1, a leftover (1−k)·xv cross-term would spoil it; the demo's V always matches the slider.) V̇ > 0 for |x| < 1 (near origin) and V̇ < 0 for |x| > 1 ⇒ trajectories spiral out from the origin and spiral in from far away. They meet on a limit cycle (oscillator). Lesson: V̇ > 0 doesn't mean unbounded growth; it means the candidate V is wrong for this system. Energy still bounds the trajectory inside the cycle.

LTI shortcut — the Lyapunov equation

For linear ẋ = Ax: pick any symmetric positive-definite Q (often the identity), solve for symmetric P in:

AᵀP + PA = −Q

If P is positive definite, then V = xᵀPx is a Lyapunov function and the system is asymptotically stable. If P comes out non-positive-definite, the system is unstable. This is a one-shot test — no eigenvalue computation needed (though equivalent for LTI). Useful when A is large or symbolic.

MATLAB: P = lyap(A', Q). Python: scipy.linalg.solve_lyapunov(A.T, -Q).

Lyapunov stability is NOT

  • Necessary for stability. A system can be stable but no easy V exists. Failing to find V doesn't prove instability — only finding one with V̇ ≥ 0 hints at it.
  • Robust to model error. Lyapunov stability of the model doesn't guarantee stability of the real system; use robust-control extensions (V̇ ≤ −ε ‖x‖² with margin).
  • Tells you HOW the system settles. Gives decay bounds (rate ≥ λ_min(Q)/λ_max(P) for LTI) but not the actual eigenstructure.
  • Equivalent to BIBO. Bounded-input-bounded-output is a different (input-output) view; Lyapunov is state-space + autonomous.
  • Useful for limit cycles. Pure Lyapunov gives equilibrium stability. For limit cycles, use Poincaré-Bendixson or compute the orbital stability via Floquet multipliers.

Common pitfalls

  • Forgetting positive definiteness — a V that's positive in one direction but negative in another (e.g., V = x₁² − x₂²) isn't a valid candidate. Check eigenvalues of the Hessian for quadratic forms.
  • Local vs global confusion — a Lyapunov function with V̇ < 0 in a neighborhood says nothing about far-away initial conditions. Estimate the region of attraction explicitly.
  • V̇ along the wrong dynamics — must use the closed-loop f(x), not just the plant or just the controller. Easy to mix these up in design problems.
  • Discrete-time uses ΔV not V̇ — for x[k+1] = f(x[k]): need V(x[k+1]) − V(x[k]) < 0 along trajectories. The continuous V̇ ≤ 0 result doesn't carry over.
  • Hybrid / switched systems — switching between stable subsystems can destabilize. Need multiple-Lyapunov-function (MLF) approach + dwell-time bounds.
  • Asymptotic vs exponential stability — V̇ ≤ −W(x) for some positive-definite W gives asymptotic. V̇ ≤ −c·V gives exponential (rate at least c). The latter is what you want for design — bounds the convergence rate.
  • Numerical V̇ estimation — when V is complicated, you may evaluate V̇ numerically along trajectories. Watch for sign changes that are actually integration noise, not true V̇ > 0.
