Response metrics

Plant: mass-spring-damper

Equation of motion: m·ẍ + c·ẋ + k·x = u(t) + d(t) with m = 1 kg, c = 0.5 N·s/m, k = 4 N/m. Sample rate dt = 1 ms, integration: explicit Euler. The controller computes u = Kp·e + Ki·∫e dt − Kd·(dy/dt) — note the derivative is on the measurement, not on the error, to avoid derivative kick on setpoint changes.

What to notice

  • Pure P leaves a steady-state error. Set Ki = Kd = 0 and watch the output settle off the setpoint. For the mass-spring-damper used here (m·ẍ + c·ẋ + k·x = u + d), the steady state under P-only control u = Kp·(r − y) gives y_ss = (Kp·r + d) / (k + Kp) and therefore e_ss = r − y_ss = (k·r − d) / (k + Kp). With no disturbance (d = 0) the output sits below the setpoint by k·r/(k+Kp); a positive load disturbance subtracts d/(k+Kp), so a big enough d can push y above the setpoint. Either way the residual scales like 1/(k + Kp), so raising Kp shrinks both contributions — until ringing appears.
  • Adding I drives the steady-state error to zero — but slowly. The integral accumulates as long as error is nonzero. Too much Ki and it overshoots, oscillates, or destabilises.
  • D adds predictive damping. Watch the overshoot collapse as Kd rises. Push it too far and the controller is dominated by noise (turn on sensor noise to see this fail loud).
  • Saturation + integrator = windup. Click the "Windup demo" preset: low actuator saturation, high Ki. With anti-windup off the integrator stuffs itself with stored error during saturation and overshoots wildly. Switch to clamping and the response recovers cleanly.
  • D on measurement vs D on error. When you step the setpoint, the implementation uses dy/dt (not de/dt), so there's no infinite-slope kick at t=0. This is the standard fix; the textbook formula is the unsafe one.
  • The "too much Kp" preset oscillates. The closed-loop poles have crossed into the unstable side. The next visual (Ziegler-Nichols) uses this point — the ultimate gain Ku — to seed PID gains.

Cheat sheet

PARALLEL PID

Parallel
u = Kp·e + Ki·∫e dt + Kd·(de/dt)
ISA / series
u = Kp·(1 + 1/(Ti·s) + Td·s)·e
Convert
Ki = Kp/Ti, Kd = Kp·Td
D on measurement
D = −Kd · (dy/dt)avoids derivative kick
Discretise
I_k = I_{k-1} + Ki·e·dt

WHAT EACH TERM DOES

  • P (proportional) — present error → bigger Kp = faster but more overshoot
  • I (integral) — past error → kills steady-state offset, can wind up
  • D (derivative) — future trend → adds damping, amplifies noise
  • Filter D — always low-pass the derivative, N = 5–20 typical

PITFALLS

  • Integral windup — actuator saturates, I keeps growing, overshoots wildly. Always clamp or back-calculate.
  • Derivative kick — D on error spikes on setpoint step. Use D on measurement instead.
  • Sample rate too slow — sample at ≥ 10× controller bandwidth. Slow loops are noisy and unstable.
  • Forgetting dt units — Ki·e·dt must use the actual loop period, not 1.
