State-space — a survey via the inverted pendulum

State-space recasts dynamics as ẋ = A·x + B·u, where x is the full state vector (positions and velocities together) and u is the input. The eigenvalues of A are the closed-loop poles in the time domain — placing them where you want is "pole placement." Full-state feedback u = −K·x can stabilise systems that PID alone cannot (the canonical example: an inverted pendulum).

Cart-pole: two-state subset (angle and angular velocity)

Linearising around the upright equilibrium gives a 2-state model (we ignore cart position for clarity): x = [θ, θ̇], input u = F (force on cart). The open-loop A matrix has one positive eigenvalue (the pendulum falls). Choose K so that A − B·K has both eigenvalues in the left half-plane, and the system stabilises.

Linearised model

For a pendulum of mass m and length L on a (massless cart), linearised about upright:

ẋ = [θ̇]     A = [  0     1  ]     B = [  0   ]
    [θ̈]         [ g/L    0  ]         [ -1/(mL) ]

eigenvalues of A: λ = ±√(g/L)   →  one POSITIVE → unstable open-loop

Pole placement: pick desired closed-loop eigenvalues λ₁, λ₂ (both negative, real). Then K is computed (Ackermann's formula in textbooks; here the controller forms u = −[k₁ k₂]·x analytically). When applied, A − B·K has eigenvalues at λ₁, λ₂.

What to notice

  • Open-loop the pendulum falls. Set mode "off" and watch θ explode. The orange pole on the right-half plane is the offender. PID on θ alone can struggle because PID has no notion of θ̇ as an independent state — it has to estimate it numerically.
  • Full-state feedback uses θ̇ as a separate signal. The K matrix has two entries: one weighs θ, the other weighs θ̇. With both states fed back, the controller has the entire phase to work with.
  • Moving the target poles to the left = faster, but bigger control force. Slide pole 1 toward −12 and watch u spike. There's no free lunch — fast convergence costs actuator effort.
  • The phase portrait is the geometric truth. A stable system spirals (or curves) into the origin. An unstable one runs outward. The closed-loop eigenvalues determine the shape: real → exponential decay, complex → decaying spiral.
  • Longer pendulum is easier to stabilise. g/L is smaller, so the unstable open-loop eigenvalue is smaller. Babies can balance a broom; nobody balances a pencil.
  • You need a state estimate. Real systems don't measure θ̇ directly; an observer (Luenberger or Kalman) reconstructs it from θ measurements + model. That's the Kalman visual.

Cheat sheet

STATE-SPACE FORMULAS

Dynamics
ẋ = A·x + B·u
Output
y = C·x + D·u
Closed-loop
ẋ = (A − B·K)·x
Stability
all eigenvalues of (A−BK) have Re < 0

CONTROLLABILITY / OBSERVABILITY

  • Controllable — rank(C_ctrl) = n where C_ctrl = [B AB A²B … Aⁿ⁻¹B]
  • Observable — rank(C_obs) = n where C_obs = [C; CA; CA²; … CAⁿ⁻¹]ᵀ
  • If not controllable — some states cannot be moved by u; can't stabilise them
  • If not observable — some states cannot be inferred from y; need extra sensors

PITFALLS

  • Linearisation only valid locally — inverted pendulum model breaks at θ ≳ 30°
  • Pole placement uses linear model — large excursions reveal nonlinear behaviour
  • Need full state x — usually requires an observer (Kalman filter visual)
  • Bad model = bad K — wrong A or B leads to wrong gains; identification matters
