The math behind the score

Handling time per part (Boothroyd-Dewhurst table simplified): T_h = T_base + ΔT_symmetry + ΔT_size T_base = 1.5 s (free fall pickup) ΔT_symmetry: α+β = 0°→ +0 s, 360° → +0.8 s, 720° → +1.5 s ΔT_size: tiny → +1.5 s, small → +0.5 s, normal → 0 s, large → +0.5 s Insertion time per part: T_i = T_base + ΔT_access + ΔT_loc + ΔT_td + ΔT_tool T_base = 1.5 s (snap-in with chamfer) ΔT_access: open → 0, restricted → +1.5 s, both → +3 s ΔT_loc: self-locating → 0, none → +1 s ΔT_td: top-down → 0, flip required → +1.5 s Fasteners add an extra +3.5 s each (manual driver) on top of part T_h + T_i Total: T_total = N · (T_h + T_i) + F · 3.5 DFA efficiency: η = (3 s · N_min) / T_total  (3 s = theoretical minimum per essential part)

The 3-test — when can a part be eliminated?

TestQuestionYES → keep separate
1. MotionDoes the part move relative to its neighbors during operation?Bearings, springs, hinges, sliders
2. MaterialMust it be a different material (electrical isolation, magnetic shielding, optical)?Glass window, insulator, magnet
3. Assembly accessMust it be separate to allow assembly of others?End caps, access covers, lids

If all three answers are NO, the part is a candidate for merging (combine geometry with neighbor) or elimination. This single rule typically halves the part count in legacy designs.

Worked example — IBM Proprinter (1985)

The redesign that defined DFA

IBM's classic dot-matrix printer rebuild — done with Boothroyd at UMass — is the canonical case study. Same function, two-thirds fewer parts, one-ninth assembly time.

MetricOriginal (1981)Proprinter (1985)Δ
Parts6532−51 %

What changed

  • All screws gone: replaced by integral plastic snap-fits — chassis sub-assemblies clip together top-down
  • Paper drive consolidated: 11 parts (gears + bracket + shaft) → 3 parts
  • Self-locating posts on chassis: cards and motors drop into precision-molded pockets, no fixtures
  • One-way orientation: most parts are obviously asymmetric so they cannot be installed wrong
  • No adjustments: tolerance stacks chosen so the design self-aligns within ±0.3 mm without tweaking

DFM principles — per-part manufacturability

ProcessKey DFM rules
Injection moldingUniform wall thickness ±25 %, 1-3° draft on all walls, ribs ≤ 50-60 % of wall thickness (avoid sink marks), no undercuts (or use side-action), gate location away from cosmetic surfaces
Sheet metalMin bend radius = 1× material thickness, flanges > 4× thickness, holes > 1.5× thickness from a bend, no narrow features < 2× thickness (cracks)
CNC millingMax pocket depth = 6× tool diameter, fillet ALL internal corners (≥ 1/8" radius for steel), pocket floors flat not rounded, avoid < 30° walls (slow), tap-call tolerances per ANSI B1.1
CNC turningL/D ratio < 5 for unsupported parts, no internal grooves narrower than smallest tool (typically 1.5 mm), thread length ≥ 1.5× diameter
FDM / FFF 3D print45° self-supporting overhang, bridges max ~5 mm unsupported, first layer wide, orient strong axis along load (Z is weakest), holes oriented vertically print better than horizontal
SLA / DLP resinDrain holes for hollow shells (≥ 4 mm dia), avoid large flat faces parallel to print plate (suction cup effect), wall thickness ≥ 1 mm for tough resin, 2 mm for standard
Sand / die castingUniform thickness (≥ 3 mm sand, ≥ 1.5 mm die), 2-3° draft, generous fillets, no sharp internal corners, plan parting line + gating before geometry
PCB (also DFM)Min trace width 0.15 mm (6 mil) for standard fabs, min via 0.25 mm hole / 0.5 mm pad, teardrops on pad-trace junctions, 8-mil thermal relief on plane connections, fiducials for SMT placement

The 10× rules of thumb

  • Part elimination saves ~10× the cost of part optimization — go after part count first, not draft angles. Halving the BOM beats shaving 5 % off injection cycle time.
  • Defects detected at design = 1×, manufacturing = 10×, field = 100-1000× — every hour of DFA review pays back in avoided ECOs and recalls.
  • One fewer part = one fewer fastener + alignment step + inventory SKU + point of failure + line-down risk. The savings cascade.
  • Snap-fits beat screws economically below ~30,000 units lifetime; above that, tooling for the integral feature pays back. Below 1,000 units, screws are cheaper.
  • DFA score > 0.4 is hard, > 0.6 is excellent, > 0.8 is exceptional — Apple's MacBook is widely benchmarked at 0.7-0.8 thanks to integrated unibody chassis.

Common pitfalls

  • Consolidating dissimilar materials — you can geometrically merge a metal heat-sink and a plastic housing, but co-molding adds tooling cost that often exceeds the saved assembly step. Run the numbers.
  • Going snap-fit on serviceable parts — snaps that can't be reopened without breakage make field repair impossible. Use snap-fits only where service is rare or impossible anyway.
  • Self-locating features only work if tolerances allow it — a 0.05 mm pocket for a 0.1 mm-tolerance post will jam. Match feature tolerance to part tolerance + 50 % margin.
  • "Standard part" trap — using an off-the-shelf component to save BOM line work fails if the standard part has a non-standard footprint or a 26-week lead time. Verify supply + footprint before committing.
  • Optimizing DFA on a 50-unit prototype — DFA wins amortize over volume. For low-volume / one-off / hand-tool builds, ease-of-rework matters more than minimum part count.
  • Forgetting electrostatic + cleanroom constraints — snap-fits can generate static; press-fits can shed particles. Process compatibility comes before geometry consolidation.
