Grasp analysis

Position control vs force control

Position-controlled gripper (cheap servo or stepper): commands a target width; if the object is smaller than expected the jaws never make contact, if larger they stall. Use when geometry is repeatable.

Force-controlled gripper (current-limited motor or pneumatic regulator): commands a target closing force; jaws close until the force-sensor or motor-current threshold is reached. Use for varying geometry, fragile objects, or deformable parts. Required for collaborative robots.

Slip detection: high-end grippers (Robotiq, Schunk EGI) have tactile arrays or skin-vibration sensors. Drop detection → instant force boost. Without sensors, retry the grasp if the post-pick image doesn't see the object.

Tool center point (TCP) and flange frame

The robot's IK solves for the flange pose (last joint frame). Real planning happens in tool0 = flange + a constant tool transform. In MoveIt 2 you set the tool offset in the URDF; in ABB / KUKA controllers you define a "tool" (TCP + tool mass + COG) and reference it on every move. Wrong TCP → the tool tip lands in the wrong spot by exactly the offset error.

What to notice

  • Friction-grip math is simple: a parallel-jaw holds against gravity if 2·μ·F ≥ m·g. Doubling friction or force; halving mass. Try mass = 5 kg, force = 40 N, μ = 0.5 → 40 N ≤ 49 N → slips.
  • Suction grip is direct: F_vacuum = ΔP · A. A 30 mm cup at 0.6 bar = 42 N straight pull. But shear is limited (~30% of normal force) and a leaky surface kills the grip.
  • Magnetic grip is direction-dependent: normal pull-off force ≫ shear force. Magnet rated 200 N pull-off may give only 40–60 N shear.
  • Three-finger gripper auto-centers regardless of where you placed the part — great for binning or feed-by-vibration applications.
  • Wrong TCP offset → the arm reaches a depth that is exactly the offset error. Re-measure after every tool change.
  • Soft fingers (urethane pads) raise effective μ by deforming around the part. Used in bin-picking + small-parts assembly.

GRIPPER PICK GUIDE

  • Repeatable rigid box → parallel-jaw, position-controlled.
  • Variable / fragile → parallel-jaw force-controlled or pneumatic Festo.
  • Round / irregular → three-finger gripper (Robotiq 3F, Schunk SDH).
  • Flat sheet, non-porous → suction (most factory pick-place).
  • Ferrous metal pile → magnetic (single-piece; multi-piece needs separator).
  • Compliant / unknown → soft / Festo BionicSoftHand or Soft Robotics mGrip.

PITFALLS

  • Wrong TCP — every motion is off by the offset error; calibrate after any tool change.
  • Wrong tool inertia — controller dynamics + torque limits use it. Heavy tool with default inertia → vibration or shutdown.
  • Suction leak — porous, dusty, or curved surfaces lose seal. Spec multi-cup arrays or compliant lips.
  • Magnet residual — part sticks after release. Use electromagnet or degausser.
  • SF=1.0 designs — they fail under acceleration. Use SF ≥ 2 static, ≥ 4 dynamic.
