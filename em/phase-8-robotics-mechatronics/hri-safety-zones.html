HRI Safety Zones & Stop Categories

When robots share space with people, the safety architecture is everything. ISO 10218 + ISO/TS 15066 define the rules: stop categories (Cat 0 / 1 / 2), speed-and-separation monitoring (SSM), and power-and-force limiting (PFL). This visual maps the zones, the standards, and the ISO 13855 math that ties speed, sensor type, and stopping time to required separation distance.

Where the distance comes from

The ISO 13855 formula

S = K · (T_s + T_d) + C S = minimum safety distance (mm) from danger zone to detection plane K = approach speed (mm/s) 2000 mm/s : hand reaching through opening (worst case) 1600 mm/s : whole-body walking approach T_s = robot stopping time after stop signal (motion → standstill) T_d = system reaction (sensor + safety relay + brake engage) C = intrusion distance — depends on sensor type: Horizontal light curtain, finger res d ≤ 14 mm: C = 0 (object detected at the plane) Horizontal light curtain, d > 14 mm: C = 8·(d − 14) ⇒ d=40 ⇒ C = 208 mm Vertical light curtain / safety fence: C = 850 mm (depth of reaching arm) Pressure mat (floor): C = 1200 mm (forward step length) Safety scanner / lidar (typical): C = 850 + 100 = 950 mm (reach + measurement uncertainty) 3D safety camera (volumetric): C = 100 mm (very close detection) Recommended mode: S ≤ 500 mm → PFL cobot only (no SSM needed) 500 < S < 1500 → SSM with monitored stop, Cat 1 or 2 S ≥ 1500 mm → industrial robot, fenced or full SSM, Cat 0/1

Cat 0 emergency stop typically requires PL d or PL e. The safety chain (sensor → safety PLC → motor disconnector) must achieve the same PL end-to-end — the weakest link sets the system PL.

Worked example — arm-6dof-pa612 on a benchtop next to a person

Scenario

The robot is mounted on a benchtop. A person stands ~0.7 m away programming the next cycle. The arm reaches 800 mm; payload is 2 kg; max TCP speed 1.5 m/s. Stopping time Ts ≈ 250 ms; system reaction Td ≈ 90 ms.

Run the math (default sensor: SICK S300 lidar, scanning 2D fan)

K = 1600 mm/s (body-walking) T_total = 0.250 + 0.090 = 0.340 s C ≈ 950 mm (lidar typical: arm reach + measurement) S = 1600 · 0.340 + 950 = 544 + 950 = 1494 mm ≈ 1.5 m

The bench is too short — 0.7 m people-distance < 1.5 m required. Options:

  • Drop into PFL mode: limit TCP speed to ~250 mm/s so even at full contact the wrist hits Annex A limits.
  • Add light curtain at 0.7 m: with d ≤ 14 mm light curtain, C = 0 → S = 544 mm only; fits 0.7 m gap.
  • Move bench: cheapest if the floor plan permits.

Common pitfalls

  • Single E-stop button on a cable is PL b at best — single point of failure. PL d requires dual-channel monitoring (two independent contacts + cross-checked by safety PLC).
  • "Cobot" + heavy payload ≠ safe — ISO/TS 15066 PFL limits depend on contact location (head most sensitive). A cobot carrying 5 kg may no longer be collaborative — SSM required.
  • Sensor blind spots — scanning lidar misses things below knee height. Always supplement with mat or light curtain at floor level.
  • E-stop test frequency — ISO 13849 requires Diagnostic Coverage. Most safety PLCs auto-test the e-stop circuit at boot + periodically (≤ 24 h).
  • Mode-switching gaps — when switching between teach-mode and run-mode, ensure there is no window where safety is briefly disabled.
  • Wearing gloves changes contact area — leather glove distributes the same force over more area, reducing pressure (good); thin nitrile concentrates it (bad). Don't certify PFL without representative PPE.
  • Tool-on-robot becomes a hazard — sharp gripper, hot end effector, sharp screwdriver. PFL covers the robot mass but not what it carries.
  • Latency budget creep — adding a network hop or PLC scan between sensor and brake increases Td. Re-run ISO 13855 every time the safety chain changes.
