Impedance Control — robot compliance via virtual spring-damper

Position control fights contact forces. Impedance control treats contact as a virtual spring-damper between the robot's commanded position and its actual position: F = K·(x_des − x) + B·(v_des − v). With K low (1–500 N/m), the robot complies softly on contact; with K high (10000+ N/m), it tracks position rigidly. Tune K and B for the task — surgical, gripping, gear insertion all need different impedance.

The math behind it

Desired dynamics: m·ẍ_e + B·ẋ_e + K·x_e = F_ext where x_e = x − x_des is position error Control law (impedance): joint torques drive end-effector toward x_des with the desired (K, B) impedance. For Cartesian impedance: τ = J^T · F_e, where F_e = K·(x_des−x) + B·(v_des−v) For joint impedance: τ_i = K_i·(θ_des,i − θ_i) + B_i·(ω_des,i − ω_i)

Choosing K and B

  • Critical damping: B = 2·√(K·m). Fastest no-overshoot response. Usually start here.
  • Under-damped (B < B_crit): faster settling but overshoots. OK for soft tasks; bad for precise insertion.
  • Over-damped (B > B_crit): slow but smooth. Good for human-robot collaboration where overshoot is bad.
  • Stiff K (10–20 kN/m): peg-in-hole assembly, robot insertion tasks. Position-dominant.
  • Mid K (500–5000 N/m): typical pick-and-place with potential collision. Forces stay manageable.
  • Soft K (10–500 N/m): surgical applications, gentle gripping, exoskeleton.

Pitfalls

  • Sample rate must be high — impedance control loop runs at > 1 kHz. Otherwise virtual spring becomes oscillatory.
  • Joint friction confounds Cartesian impedance — Jacobian-transpose torque assumes joints are friction-free. Add friction compensation.
  • Singularities — at Jacobian singularities, infinite torque commanded. Use damped least-squares pseudo-inverse to bound torque.
  • Force sensing for admittance — admittance control requires fast force-torque sensor (≥ 1 kHz) and clean signal. F/T sensor noise feeds into position command.
  • Stability with environment stiffness — soft robot + stiff environment can chatter. Pick K_robot < K_environment for stable contact.
