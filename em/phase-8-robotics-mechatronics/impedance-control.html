Impedance Control — robot compliance via virtual spring-damper

Position control fights contact forces. Impedance control treats contact as a virtual spring-damper between the robot's commanded position and its actual position: F = K·(x_des − x) + B·(v_des − v). With K low (1–500 N/m), the robot complies softly on contact; with K high (10000+ N/m), it tracks position rigidly. Tune K and B for the task — surgical, gripping, gear insertion all need different impedance.

The math behind it

Desired dynamics: m·ẍ_e + B·ẋ_e + K·x_e = F_ext where x_e = x − x_des is position error Control law (impedance): joint torques drive end-effector toward x_des with the desired (K, B) impedance. For Cartesian impedance: τ = J^T · F_e, where F_e = K·(x_des−x) + B·(v_des−v) For joint impedance: τ_i = K_i·(θ_des,i − θ_i) + B_i·(ω_des,i − ω_i)

Choosing K and B

  • Critical damping: B = 2·√(K·m). Fastest no-overshoot response. Usually start here.
  • Under-damped (B < B_crit): faster settling but overshoots. OK for soft tasks; bad for precise insertion.
  • Over-damped (B > B_crit): slow but smooth. Good for human-robot collaboration where overshoot is bad.
  • Stiff K (10–20 kN/m): peg-in-hole assembly, robot insertion tasks. Position-dominant.
  • Mid K (500–5000 N/m): typical pick-and-place with potential collision. Forces stay manageable.
  • Soft K (10–500 N/m): surgical applications, gentle gripping, exoskeleton.

Pitfalls

  • Sample rate must be high — impedance control loop runs at > 1 kHz. Otherwise virtual spring becomes oscillatory.
  • Joint friction confounds Cartesian impedance — Jacobian-transpose torque assumes joints are friction-free. Add friction compensation.
  • Singularities — at Jacobian singularities, infinite torque commanded. Use damped least-squares pseudo-inverse to bound torque.
  • Force sensing for admittance — admittance control requires fast force-torque sensor (≥ 1 kHz) and clean signal. F/T sensor noise feeds into position command.
  • Stability with environment stiffness — soft robot + stiff environment can chatter. Pick K_robot < K_environment for stable contact.

Worked example — peg-in-hole assembly

The task

Insert a 10 mm steel peg into a 10.1 mm hole. Clearance is 100 µm — much less than typical robot positioning accuracy (~1 mm). A position-controlled robot would jam or break the peg. Impedance control allows the peg to "slide" along the chamfer until aligned.

Impedance choice (lateral)

Soft in lateral directions, stiff in vertical insertion direction (selective compliance):

K_lateral = 500 N/m (lateral position error of 100 µm produces 0.05 N — peg slides freely)
B_lateral = 30 N·s/m → for m = 0.2 kg: ζ = 30/(2·√(500·0.2)) = 1.5 (over-damped, no oscillation)
K_vertical = 5000 N/m (sufficient to push 0.5 N insertion force when at target position)
K_vertical: too high → jams against chamfer; too low → doesn't insert. 5000 N/m is a typical sweet spot.

Result

Robot commands position above-and-into the hole. If the peg hits the chamfer, lateral force pushes the peg sideways (with K_lateral compliance), the robot's lateral position drifts to follow, and the peg slides into alignment with the hole. Insertion completes naturally. Typical success rate > 95 % even with ±2 mm positioning uncertainty.

Hogan's classification — task-relevant impedance

Neville Hogan (MIT, 1985) classified impedance control by what it regulates. Each is appropriate for a different task:

TypeRegulatedTask
Position controlPosition only (infinite K)Free-space motion, no contact
Impedance (passive)K, B, M — virtual mechanical impedanceConstrained motion, assembly, gentle gripping
Impedance (active)K, B, M shaped by feedbackSame as passive but lower achievable impedance
AdmittanceInverse: measure F, command motionStiff environment + sensor noise OK; faster contact response
HybridPosition in some directions, force in othersSurface tracking (polishing, deburring)
Variable impedanceK(t), B(t) modulated during taskHuman-robot collaboration; stiff during transport, soft on contact

Cartesian vs joint impedance

  • Joint impedance — each joint gets its own (K_i, B_i). Simple, robust, decoupled from kinematics. But the end-effector compliance depends on the Jacobian, varying across the workspace.
  • Cartesian impedance — desired stiffness K_C ∈ ℝ^6×6 is specified in task space. Joint torques computed as τ = J^T · K_C · (x_des − x). Constant Cartesian behavior, but breaks down at singularities.
  • Hybrid — joint impedance for safety + position control + Cartesian impedance overlay near the workpiece. KUKA iiwa, Franka Emika Panda, FrankaResearch3 all support this natively in their controllers.

Stability — the colocation requirement

For an impedance controller to be stable in contact with a passive environment (Lyapunov), the robot must appear as a passive port from the environment's viewpoint. Several requirements:

  • Co-location — the force sensor (or virtual point of compliance) must be at the same location as the position controller. Separated → non-collocated mode instability (the flexible mode between sensor and actuator goes unstable).
  • Damping ≥ minimum threshold — too low B = no energy dissipation, robot rings against the environment.
  • Sampling-rate Nyquist — the impedance loop must run at >> ω_n. For K = 1000 N/m, m = 1 kg → ω_n = 31.6 rad/s = 5 Hz. Loop at 1000 Hz is plenty. For K = 10000, ω_n = 100 rad/s = 16 Hz → loop at 200 Hz minimum.
  • Render-impedance > actuator stiffness — actuator's intrinsic stiffness (gear ratio + motor encoder resolution) limits the minimum K. A geared motor naturally renders K ~10000+ N/m even with controller commanding K = 100.

Cheat sheet

FORMULAS

F = K·(x_d − x) + B·(ẋ_d − ẋ) + M·(ẍ_d − ẍ)
ω_n = √(K/M)
ζ = B / (2·√(K·M))
t_settle ≈ 4/(ζ·ω_n)
τ_jt = JT·F_task (joint torque)

PICK K / B BY TASK

  • Free-space tracking: K=∞ stiffness, position-control mode
  • Polishing / sanding: K=100-500 N/m normal, ∞ tangential
  • Assembly insertion: K=500-2000 N/m radial, low B (allow give)
  • Hand-guiding: K=0, B=20-50 Ns/m (viscous, no spring)
  • Co-manipulation (surgical): K=200, B=10 (gentle resistance)
  • Walking / running: K=1000-10000 N/m varied by phase

PITFALLS

  • Loss of co-location — F-sensor and controller at different rigid links → instability
  • Discretized B too small — undamped ringing in contact at sample boundary
  • High intrinsic gear stiffness floors min-K renderable
  • Force-sensor noise injected as virtual motion — filter the F signal
  • Singular Jacobian at singularities — F_task huge; soft-limit τ_jt
  • Forget M for fast contacts — pure K-B works at low bandwidth only
