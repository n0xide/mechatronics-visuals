The closed-form IK

Given target (x, y) and link lengths L₁, L₂, set d² = x² + y². By the law of cosines on the triangle base–elbow–tool:

cos θ₂ = (d² − L₁² − L₂²) / (2·L₁·L₂)

If |cos θ₂| > 1 the target is unreachable. Otherwise the two solutions are θ₂ = ±acos(...) (elbow-down vs elbow-up). Then:

θ₁ = atan2(y, x) − atan2(L₂·sin θ₂, L₁ + L₂·cos θ₂)

For a real 6-DOF arm with a spherical wrist, the same logic generalises analytically (kinematic decoupling: solve position with the first 3 joints, orientation with the last 3). When the geometry has no closed form, fall back to numerical IK (damped least squares).

What to notice

  • Two solutions per reachable point. Same (x, y), different joint configuration. Path planners must pick one and stay on it — switching branches mid-trajectory swings the elbow violently.
  • Unreachable zones are clearly visible. Inside |L₁−L₂| (hole around the base) and outside L₁+L₂ (outer ring). Click in them — the solver returns no real solution.
  • Singularity at full extension. When d = L₁+L₂, both solutions collapse to θ₂ = 0. The Jacobian loses rank and joint velocities blow up to maintain tool velocity. Avoid passing through this in motion.
  • Singularity at full fold. When d = |L₁−L₂|, both solutions collapse to θ₂ = ±180°. Same loss of rank.
  • atan2 not atan. The four-quadrant atan2 is essential — plain atan loses sign info and can put θ₁ in the wrong quadrant.
  • "Trace a circle" demo reveals branch flips: as the target sweeps near the boundary, the two solutions cross. A controller using a single branch will see a discontinuous jump.

IK STRATEGY DECISION

  • Analytic (closed form) — fastest, deterministic. Use when geometry permits (planar arms, spherical-wrist 6-DOF).
  • IKFast — auto-generates analytic IK from URDF; preferred for production arms.
  • TracIK / KDL — numerical, handles arbitrary geometry; default in MoveIt 2.
  • Damped least squares — gracefully handles singularities; small λ² traded off vs accuracy.

PITFALLS

  • Branch flipping mid-path — picking a different IK solution between samples = sudden joint motion. Pick a branch and bias toward it.
  • Singularity in the middle of a Cartesian path — joint velocities spike. Avoid by re-planning in joint space across the singularity.
  • Near-singular targets — even before reaching the boundary, condition number of J explodes. Throttle Cartesian speed near the edge of the workspace.
  • Forgetting orientation — planar IK gives (x,y); a 6-DOF IK must satisfy position + orientation. Wrist offsets matter.
