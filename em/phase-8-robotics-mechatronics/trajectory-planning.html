Joint-space vs Cartesian — when to use what

Joint-space: interpolate each θᵢ linearly (or via spline) from start joints to goal joints. The tool traces whatever curve falls out of the FK. Fast, smooth, no IK at runtime — but unpredictable in workspace. Use for free-space moves between unobstructed waypoints.

Cartesian-space: interpolate (x, y) linearly between start and goal. Run IK at each sample to get joint angles. Tool path is a straight line in space — required for welding, painting, deposition, inspection. Risk: path may pass through a singularity or be unreachable in segments.

What to notice

  • Same endpoints, different paths. Toggle both arms and run a move — the blue arm cuts a smooth arc; the orange arm holds the straight line.
  • Joint-space is always feasible if both endpoints are reachable. No IK failures mid-motion.
  • Cartesian-space can fail mid-motion. If the straight line crosses outside the workspace or through a singularity, the segment dies. MoveIt's Cartesian planner returns a fraction (e.g., "completed 0.62 of path").
  • Trapezoidal profile = constant accel ramp, constant velocity cruise, constant decel ramp. Three-segment, jerk is impulsive at corners.
  • S-curve profile = limits jerk. Acceleration ramps up smoothly, holds, ramps down. Slightly longer for same move; massively reduces vibration on stiff servos.
  • Quintic polynomial = single 5th-order curve through both endpoints with matching velocity and acceleration. Smoothest of all; cannot impose a fixed cruise velocity.

Cheat sheet

TIME SCALING

Normalised time
s(t) ∈ [0, 1], t ∈ [0, T]
Linear
s = t/T
Quintic
s = 10τ³ − 15τ⁴ + 6τ⁵, τ = t/T
Path point
p(t) = p₀ + s(t)·(p₁ − p₀)
Trap. timing
T = (v_max/a) + Δp/v_max
S-curve constraint
|jerk| ≤ j_max in every segment

WHEN TO USE WHICH

  • Joint-space + trapezoidal — default for free-space moves; fastest.
  • Cartesian + S-curve — welding, painting, glue dispensing, machining; predictable tool path + smooth servo command.
  • Quintic — short, precise moves where smoothness wins over speed.
  • OMPL planner (RRT*) when there are obstacles; output is a joint-space path, then time-parameterise with trapezoidal/S-curve.

PITFALLS

  • Picking Cartesian for free-space moves — risks singularities and IK failures for no benefit.
  • Joint discontinuity between waypoints — IK branch flip mid-Cartesian-segment swings joints violently. Constrain or check branch continuity.
  • Trapezoidal on stiff servos — corner jerk excites resonance; switch to S-curve.
  • Forgetting joint velocity/accel limits — Cartesian planners often demand more joint speed than the motor can deliver near singularity.
