Circuits cookbook — reusable patterns

A pattern library of small, proven circuit + firmware recipes. Each card has a schematic, a one-line "when to use", the key formula, common values, and the trap that bites people. Filter by category at the top. These are the building blocks behind 80 percent of mechatronics designs — recognise them once and you stop reinventing them.

— recipes

Reverse-polarity P-FET

Power

A device might be plugged backward and you want zero voltage drop (~mV).

Formula
V_drop = I · R_DS(on)
Values
R_DS(on) < 50 mΩ, V_GS(th) < 3 V, Zener 10–12 V
Gotcha
Body diode conducts before FET turns on — brief reverse current during inrush.

Schottky reverse-polarity diode

Power

Low-current loads where ~0.3 V drop is acceptable.

Formula
P_loss = V_f · I_load (≈ 0.3 W per A)
Values
SS14 (1 A), SS34 (3 A), SS54 (5 A); V_R ≥ 2× V_in
Gotcha
Schottky leakage rises sharply with temperature — bad for low-power sleep.

Soft-start NTC inrush limiter

Power

Mains-powered supply with large bulk caps — limit the inrush spike at plug-in.

Rule
R_cold ≈ V_peak / I_inrush_target
Values
SCK series: 5 Ω/5 A, 10 Ω/3 A; place before bridge rectifier
Gotcha
NTC stays hot — if you hot-plug quickly, R hasn't recovered. Add a bypass relay for cycle-tolerant supplies.

Bulk + ceramic bypass pair

Power

Every IC. Bulk handles low-f droop, ceramic handles fast switching transients.

Pair
1× bulk (µF) + 1× 100 nF per Vcc pin
Values
10–100 µF bulk; 100 nF 0402/0603 within 5 mm of pin
Gotcha
Two ceramics with mismatched values create an anti-resonance dip; keep parallel decoupling within 1 decade.

LDO with input + output cap

Power

3.3 V or 5 V rail from a higher source; small load (<500 mA) where switching noise matters.

Headroom
V_in ≥ V_out + V_dropout (≈ 1.1 V for AMS1117)
Values
10 µF in, 22 µF out (LDOs often require min ESR); ground both at one point
Gotcha
Some LDOs oscillate without a ceramic with specific ESR — read the datasheet stability section.

Input fuse + TVS clamp

Power

Front of every input that might see ESD, surge, or accidental overvoltage.

Order
fuse first → TVS clamps → bulk cap
Values
Fuse = 1.5× steady current; TVS V_BR ≈ 1.3× V_nominal, bidirectional for AC
Gotcha
TVS without a fuse just dies silently after one big surge. Fuse is the consumable.

Pull-up + GPIO + Schmitt

Digital in

Any switch, button, optocoupler output, or open-drain sensor input.

Rule
R_pu × I_leak ≪ V_IL ; R_pu × C_line ≤ desired rise τ
Values
10 kΩ default; 1–4.7 kΩ for noisy/long lines; internal pull-up = ~30–50 kΩ
Gotcha
Floating input without pull-up reads garbage and burns power oscillating around threshold.

Button debounce RC + Schmitt

Digital in

Tactile button into MCU; preferred over software debounce when timing is tight.

Formula
τ = R · C ≈ 1 ms ; 5τ ≈ 5 ms settle
Values
R = 10 kΩ, C = 100 nF; pair with Schmitt-trigger input or 74HC14 inverter
Gotcha
Without Schmitt hysteresis you get multiple edges on the slow ramp through V_threshold.

Optocoupler isolation

Digital in

Crossing voltage domains (mains→logic, motor→logic), or breaking ground loops.

Formula
R_LED = (V_in − V_f) / I_LED ; CTR = I_C / I_LED
Values
PC817: I_LED 10–15 mA, CTR 50–600 %; output pull-up 4.7–10 kΩ
Gotcha
CTR drops with age and temperature — design for the min CTR, not typical.

N-MOSFET low-side switch

Loads

Switching motors, LEDs, heaters from logic — load returns to V+, FET sinks to GND.

Formula
P_diss = I² · R_DS(on) ; τ_sw = R_g · C_iss
Values
Logic-level FET (V_GS(th) ≤ 2.5 V); R_g 47–220 Ω; R_pulldown 10 kΩ
Gotcha
Standard FETs need V_GS = 10 V to turn on fully — read "logic level" in the part number.

P-MOSFET high-side switch

Loads

Battery-side power switch, sleep-mode load disconnect, "soft power button".

On
V_GS = −(V_BAT) when NFET sinks gate
Values
V_GS(max) typically ±20 V — clamp gate to V_BAT with Zener if V_BAT > 18 V
Gotcha
If MCU boots after V_BAT, gate floats high (off). Need pull-up so default state is off, not glitchy.

H-bridge (4 FETs + drivers)

Loads

Bidirectional DC motor, voice coil, or stepper coil drive.

Rule
Forward = HSA+LSB ; Reverse = HSB+LSA ; never HS+LS same side
Values
Use gate driver (DRV8870/L298 integrated, or DRV8701 for discretes); 1–4 µs dead-time
Gotcha
Shoot-through (both HS+LS on briefly) cooks both FETs in microseconds. Dead-time is non-negotiable.

Flyback diode (relay/solenoid)

Loads

ANY inductive load driven by a transistor: relays, solenoids, brushed DC motors.

Why
V_L = −L · dI/dt → kV spikes destroy FETs without clamp
Values
1N400x for slow coils, UF400x or Schottky for PWM motors (faster recovery)
Gotcha
Diode increases relay release time. Add series Zener (~24 V) for snappy release at cost of more stress.

Voltage divider for ADC

Analog

Measure a voltage above the ADC reference (battery, rail monitor).

Formula
V_adc = V_in · R2/(R1+R2)
Values
Keep R1‖R2 ≤ 10 kΩ for SAR ADCs; add 1–10 nF cap at ADC pin for filtering
Gotcha
High-impedance divider + low ADC sample time = wrong reading (sample cap can't charge in time).

RC anti-alias before ADC

Analog

Always — before any ADC pin, even when "the signal is slow".

Formula
f_c = 1/(2π·R·C) ; pick f_c < f_s/2
Values
1 kΩ + 100 nF → f_c ≈ 1.6 kHz (good for 10–20 kSPS)
Gotcha
No filter = aliases of switching noise and EMI land squarely in your signal band.

Op-amp buffer (impedance isolation)

Analog

Source is high-Z (thermistor, MEMS, voltage reference) and load draws current.

Formula
V_out = V_in ; Z_in ≈ ∞ ; Z_out ≈ 0
Values
Rail-to-rail opamp if signal nears V_cc/GND; bandwidth × gain product matters
Gotcha
Some opamps oscillate at unity gain — check the datasheet for "minimum stable gain".

In-amp on Wheatstone bridge

Analog

Load cell, strain gauge, RTD bridge — measure tiny ΔV in presence of large common-mode.

Formula
V_out = G · (V+ − V−) ; G = 1 + 49.4kΩ/R_G (INA128)
Values
INA128/INA826/AD623; G = 100–1000 for load cells; ratiometric ADC if you can
Gotcha
CMRR collapses if source impedance is unbalanced — match the two input source-Rs.

Current sense (shunt + diff amp)

Analog

Motor current, battery monitor, OCP — convert I to a usable voltage with low loss.

Formula
V_shunt = I · R_s ; V_out = V_shunt · G
Values
Aim V_shunt(max) ≈ 50–100 mV; INA240 (high-side) or INA181 (50/100/200 V/V)
Gotcha
Kelvin-sense the shunt — share only the sense traces, not the load current path.

Inverting summing amp

Analog

Mix two signals with independent gain; build a single-supply offset.

Formula
V_o = −R_f · (V1/R1 + V2/R2)
Values
R_f sets max gain; equal Rs sum equally; bias V+ to mid-rail on single-supply
Gotcha
Single-supply opamp clamps at 0 V — the inverter literally cannot make a negative output. Use mid-rail virtual GND.

I²C pull-ups + bus cap budget

Comms

Every I²C bus. Open-drain needs pull-up to assert high.

Formula
R_min = (V_cc−0.4)/3mA ; R_max ≈ 1µs/C_bus
Values
4.7 kΩ (3.3 V), 2.2 kΩ (5 V, fast); ≤400 pF total bus capacitance
Gotcha
Two devices each with internal pull-ups effectively halve the resistance — bus may go too "stiff".

SPI level shifter (3V3 ↔ 5V)

Comms

3V3 MCU talking to a 5V level chip (older sensors, SD-card adapter, display).

Topology
N-MOSFET bidirectional shifter (BSS138/2N7000)
Values
10 kΩ pull-ups; one FET per line; or use TXB0108/74LVC chip
Gotcha
Pull-ups limit SPI speed — for > 5 MHz, use a dedicated buffer not passive shifter.

RS-485 termination (120 Ω each end)

Comms

Multidrop RS-485, CAN, anything on a long differential pair (> 1 m).

Rule
R_term = Z_0 of cable (≈ 120 Ω for twisted pair)
Values
120 Ω at each physical end of the bus (only); add 680Ω bias to A high/B low
Gotcha
Two terminators in the middle (or none) — reflections, retries, comms storm. Verify with multimeter (60 Ω).

UART galvanic isolation

Comms

Talking to a noisy motor controller, mains-side MCU, or RS-232/485 PHY on a separate supply.

Rule
Each side gets its own GND + decoupling cap
Values
ADuM1201 (2-ch), Si8642 (4-ch); isolation 2.5–5 kV; 1–25 Mbps
Gotcha
Forgetting to isolate power too — only the signal is isolated. Add an isolated DC-DC if the secondary side needs power.

CAN bus terminator (split 60Ω)

Comms

CAN/CAN-FD network endpoints — improves EMC vs single 120 Ω.

Rule
2× 60 Ω in series at each end ; cap to GND for CM filter
Values
60.4 Ω 1% E96, 4.7 nF C0G; terminate exactly two nodes (ends of trunk)
Gotcha
Splitting is for EMC; if you stub-drop > 30 cm to a node, you'll still see reflections.

millis() cooperative scheduler

Firmware
// Non-blocking periodic tasks
struct Task { uint32_t last, period; void(*fn)(); };
Task tasks[] = {
  {0, 10,  read_sensors},
  {0, 20,  run_pid},
  {0, 100, update_display},
  {0, 1000,heartbeat},
};
void loop() {
  uint32_t now = millis();
  for (auto& t : tasks) {
    if (now - t.last >= t.period) {
      t.last = now;
      t.fn();
    }
  }
}

Arduino/Pico sketches with multiple periodic jobs — replace delay() once and for all.

Trick
use unsigned subtraction → rollover-safe at 49 days
Values
periods at logical rates; keep each fn() < shortest period
Gotcha
A long task delays everything after it — fast tasks first, or split work.

Ring buffer UART RX

Firmware
#define N 128     // power-of-2
static volatile uint8_t buf[N];
static volatile uint8_t head=0, tail=0;

// ISR — keep tiny
void UART_IRQHandler() {
  buf[head] = UART->RXDR;
  head = (head + 1) & (N-1);
  // dropped if head catches tail; bump stat
}
// foreground
int read_byte() {
  if (head == tail) return -1;
  uint8_t b = buf[tail];
  tail = (tail + 1) & (N-1);
  return b;
}

Streaming bytes from UART, USB CDC, BLE — anywhere you can't poll fast enough.

Rule
Power-of-two size → mask instead of modulo
Values
64–256 bytes typical; mark volatile; consider lock-free SPSC pattern
Gotcha
Reading head twice in foreground can race with ISR — snapshot to local var.

ISR defers to task

Firmware
volatile bool sensor_ready = false;

// ISR: just signal — no I²C, no printf, no float
void EXTI_IRQHandler() {
  sensor_ready = true;
  EXTI->PR = bit;     // clear flag
}

void loop() {
  if (sensor_ready) {
    sensor_ready = false;
    read_imu();        // long I²C burst lives here
    process_data();
  }
}

Sensor data-ready pin, timer tick, button — anywhere you'd be tempted to do work in the ISR.

Rule
ISR does the minimum: set flag, ack, return
Values
flag = volatile bool ; for RTOS use semaphore/queue
Gotcha
Long ISR blocks other interrupts — UART overrun, CAN bus-off, lost edges.

PID step (Euler, anti-windup)

Firmware
float integ = 0, y_prev = 0;

float pid_step(float r, float y, float dt) {
  float e = r - y;
  float P = Kp * e;
  float D = -Kd * (y - y_prev) / dt; // D on measurement
  integ += Ki * e * dt;
  float u = P + integ + D;
  if (u > U_MAX) { u = U_MAX; integ -= Ki*e*dt; }
  if (u < U_MIN) { u = U_MIN; integ -= Ki*e*dt; }
  y_prev = y;
  return u;
}

Closed-loop motor speed, temperature, position — the workhorse loop.

Formula
u = Kp·e + Ki·∫e·dt − Kd·dy/dt
Values
dt = loop period in seconds; sample ≥ 10× plant bandwidth
Gotcha
D-on-error spikes at setpoint step. Use D-on-measurement (above) by default.

Table-driven FSM

Firmware
enum State { IDLE, ARMED, RUN, FAULT };
enum Event { BTN, TICK, ERR };

struct Trans { State s; Event e; State next; void(*act)(); };
static const Trans T[] = {
  { IDLE,  BTN,  ARMED, arm     },
  { ARMED, TICK, RUN,   spin_up },
  { RUN,   BTN,  IDLE,  stop    },
  { RUN,   ERR,  FAULT, fail    },
};

State s = IDLE;
void dispatch(Event ev) {
  for (auto& t : T)
    if (t.s == s && t.e == ev) {
      t.act(); s = t.next; return;
    }
}

UI flows, motor commissioning sequence, anywhere "if (state == X)" trees are growing.

Why
data table → reviewable, testable, extensible
Values
add ENTRY/EXIT actions per state for hierarchical FSM
Gotcha
Forgotten event in a state → silent no-op. Add a default "log unhandled" rule.
