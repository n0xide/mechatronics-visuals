Ring buffer (power-of-2)

Firmware
// SIZE must be power of 2
#define SZ 64
uint8_t buf[SZ];
volatile uint8_t head, tail;

push(uint8_t c) {
  buf[head & (SZ-1)] = c;
  head++;
}
pop(uint8_t *c) {
  if (head == tail) return 0;
  *c = buf[tail++ & (SZ-1)];
  return 1;
}

UART RX / TX queues, sensor sample buffers — any producer-consumer where you can't lose bytes.

SZ = 2^Nsingle producer + single consumer

Cooperative scheduler (millis)

Firmware
struct Task { uint32_t next; uint32_t period; void(*fn)(); };
Task ts[] = {
  {0,   10, sample_adc},
  {0,  100, blink_led},
  {0, 1000, telemetry},
};
void loop() {
  uint32_t now = millis();
  for (auto& t : ts)
    if ((int32_t)(now - t.next) >= 0) {
      t.next += t.period;
      t.fn();
    }
}

LUT + linear interpolation

Firmware
// thermistor: 32 points, monotonic
const int16_t T_TBL[32] = { ... };  // ×10 °C

int16_t temp_c10(uint16_t adc) {
  uint8_t i = adc >> 7;        // 4096→32
  if (i >= 31) return T_TBL[31];
  uint16_t frac = adc & 0x7F;  // 0..127
  int16_t y0 = T_TBL[i], y1 = T_TBL[i+1];
  return y0 + ((int32_t)(y1-y0) * frac >> 7);
}

// 1 kHz × 256 = 256 Hz PWM, 8 ch
void tick() {
  cnt++;
  for (uint8_t i = 0; i < 8; i++)
    digitalWrite(i, cnt < duty[i]);

How to read each card

The card view is the index. Each card is the recipe at a glance: title and category, a clean SVG snippet of the topology, the headline use-case, and the part numbers and key formula as micro-tags. Click any card for the full version: an expanded schematic, the math (with annotations), bill of materials, the "when to use vs not" decision rule, common alternatives, the gotcha that has bitten people in practice, and cross-links to the other visuals where the same circuit appears in a different context.

How to use this library day-to-day

This is a working reference, not a textbook. Three workflows it supports:

  • Looking up by name — you remember the topology but not the values ("P-FET reverse polarity gate Zener"). Search by tag, take what you need, close the tab.
  • Browsing by category — you know you need to switch a load but haven't decided how. Filter Digital out, scan the four switch recipes side by side, pick the right one for your gate-drive headroom and load profile.
  • Cold review — you're reviewing a schematic and want a sanity check. Search the IC part number, read the gotcha, decide whether the schematic is missing anything.

The Random recipe button is for the fourth workflow — passive learning. Hit it before a study session to surface a pattern you haven't thought about lately.
