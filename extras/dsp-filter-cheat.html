DSP & Filter Cheat Card

The core math behind digital signal processing — sampling, the FFT, FIR vs IIR filters, windowing, and the choice between them. Every embedded system that touches a sensor or audio signal needs DSP. This card distills the must-know formulas + design rules.

Nyquist: fs ≥ 2·f_max (no aliasing) Practical fs: 4-10× f_max FFT cost: N·log₂(N) operations FIR: linear phase, stable always IIR: efficient, may be unstable

Sampling — Nyquist + anti-aliasing

Nyquist criterion: sample rate fs must be at least 2× the highest signal frequency f_max If you sample below 2·f_max: aliasing — signals at >fs/2 fold back into the baseband. Permanent loss of info. Practical rule: pick fs = 4-10× f_max for headroom. Anti-alias filter at ~fs/3 in analog before ADC. Sample-rate examples: audio CD = 44.1 kHz (covers 0-20 kHz); IMU = 1-8 kHz (motion freq < 100 Hz); current sense = 20-100 kHz (PWM at 20 kHz).

The DFT and FFT

The Discrete Fourier Transform converts N time-domain samples into N frequency-domain bins:

X[k] = Σ_{n=0..N-1} x[n] · exp(-j·2π·k·n/N) Direct DFT: O(N²) operations FFT (Cooley-Tukey): O(N log N) — for N=1024, 10× faster; for N=1M, 50,000× faster Frequency resolution: Δf = fs / N — finer if you take more samples Time resolution: ΔT = N / fs — coarser if you take more samples (the uncertainty principle)

Windowing — taming spectral leakage

An FFT of a non-periodic signal exhibits "leakage" — energy from one frequency spreads to adjacent bins. Windowing tapers the signal at both ends to reduce this.

The biquad — IIR's building block

Any IIR filter can be implemented as a cascade of biquads — 2nd-order sections. A biquad has the difference equation:

y[n] = (b0·x[n] + b1·x[n-1] + b2·x[n-2]
        − a1·y[n-1] − a2·y[n-2]) / a0

5 coefficients (a0 typically normalized to 1). Filter designers compute the coefficients from desired cutoff + Q + filter type.

Worked example — designing a low-pass for IMU smoothing

Setup

MPU-6050 IMU at 1 kHz sample rate. We want to smooth accelerometer data with cutoff at 50 Hz to filter out vibration noise.

Filter choice

Butterworth IIR, 2nd order (one biquad). Cutoff fc = 50 Hz.

Normalized cutoff: w0 = 2π·50/1000 = 0.314 rad/sample Q = 0.707 for Butterworth From RBJ cookbook LPF: α = sin(w0) / (2·Q) = 0.219 cos_w0 = cos(0.314) = 0.951 b0 = (1 - cos_w0) / 2 = 0.0245 b1 = 1 - cos_w0 = 0.0489 b2 = (1 - cos_w0) / 2 = 0.0245 a0 = 1 + α = 1.219 a1 = -2·cos_w0 = -1.902 a2 = 1 - α = 0.781

C code (single biquad, direct form II transposed)

typedef struct { float b0,b1,b2,a1,a2; float z1,z2; } biquad_t;

float biquad_step(biquad_t *b, float x) {
    float y = b->b0 * x + b->z1;
    b->z1   = b->b1 * x + b->z2 - b->a1 * y;
    b->z2   = b->b2 * x        - b->a2 * y;
    return y;
}

One biquad = 5 multiplies + 4 adds per sample. At 1 kHz, takes 9 µs on a Cortex-M4F. Negligible.

Common DSP recipes

Moving average (boxcar) filter

Simplest FIR: average last N samples. Linear phase. N=5 gives ~6 dB attenuation at fs/(2N). Good for: smoothing noisy sensor data when phase doesn't matter much.

float avg = 0;
for (int i = 0; i < N; i++) avg += buf[(idx-i) % N];
avg /= N;

Exponential moving average (EMA, "leaky integrator")

One-pole IIR: y[n] = α·x[n] + (1-α)·y[n-1]. α between 0 (no update) and 1 (no filter). Cutoff ≈ α·fs / (2π).

// alpha sets cutoff. alpha = 0.1 at 1 kHz ≈ 16 Hz LPF
y = alpha * x + (1 - alpha) * y_prev;
y_prev = y;

Notch filter for 60 Hz hum (US mains pickup)

2nd-order biquad with Q=10 at fc=60 Hz removes ±0.5 Hz around 60. Use in audio + biomed.

FFT-based spectral analysis

// Capture N samples, apply window, FFT, magnitude
window_hann(buf, N);
fft(buf, N);  // CMSIS-DSP: arm_rfft_q15(...)
for (int k = 0; k < N/2; k++) {
    magnitude[k] = sqrtf(re[k]*re[k] + im[k]*im[k]);
}

Performance tips

  • Use CMSIS-DSP on Cortex-M — hand-tuned ARM-optimized FFT/biquad/FIR. Up to 10× faster than naive C.
  • Use Q15 or Q31 fixed-point on M0/M0+ without FPU. M4F and up: just use float.
  • Pre-allocate buffers; never malloc in DSP callbacks.
  • Use double-buffering for DMA-fed ADC: process buffer N while DMA fills buffer N+1.
  • Watch for accumulator overflow in fixed-point FIR with many taps. CMSIS handles this via 64-bit accumulator internally.
  • For order-100+ FIR: switch to overlap-add FFT convolution — faster than direct convolution past ~100 taps.

Z-domain and stability

An IIR filter's stability depends on its poles — the roots of the denominator polynomial. For stability, all poles must lie inside the unit circle in the complex z-plane.

Transfer function: H(z) = (b0 + b1·z⁻¹ + b2·z⁻²) / (1 + a1·z⁻¹ + a2·z⁻²) Poles: roots of (1 + a1·z⁻¹ + a2·z⁻²) = 0 For biquad: |poles| < 1 ⇔ |a2| < 1 AND |a1| < 1 + a2 Coefficient quantization in fixed-point can move poles outside the circle → instability.
