The IPC formula (with derivation)

IPC-2221 (and its successor IPC-2152) gives an empirical fit from the 1956 Brooks current-rise charts. The form solves for the cross-sectional area needed to limit conductor temperature rise to ΔT:

Start: I = k · ΔT^0.44 · A^0.725  (A in mil², I in A, ΔT in °C) k coefficient (note: external traces dissipate heat better, so they need less area at the same current — higher k): I_external = 0.048 · ΔT^0.44 · A^0.725  (top/bottom layer, exposed to air) I_internal = 0.024 · ΔT^0.44 · A^0.725  (inner layer, surrounded by FR-4) Solve for A: → A = (I / (k · ΔT^0.44))^(1/0.725)  [mil²] Width: W = A / thickness  (1 oz Cu = 1.378 mil thick · 2 oz = 2.756 mil · 0.5 oz = 0.689 mil)

IPC-2152 (newer) adds variables for plane proximity, board thickness, and via density. The result is usually narrower traces than 2221 says — 2221 is conservative. Most CAD tools still ship the 2221 charts because the math is one line.

Where you'll see this

  • Power-supply input traces — buck/boost input rail at 3–5 A on 1 oz Cu needs 1.5–2 mm. Most hobby boards are 1 oz; pour copper if you need more.
  • Motor driver outputs — H-bridge phases at 1–2 A peak need 0.5–1 mm. Don't forget the return path — same trace width on GND.
  • USB-PD / charger inputs — 3 A @ 20 V means 1.5 mm minimum, and most PD spec docs require thermal relief on connector pins.
  • Battery main lines — for a 1S LiPo at 2 A peak (cyberdeck typical), use 0.8–1.0 mm wide; on a Pico Lipo board, this is the trace from the cell connector to the load switch.

What to watch for

  • IPC-2221 is conservative on long runs — the formula assumes infinite trace; short traces (< 5 × width) actually dissipate via the pads. For pin-to-pin runs of a few mm, you can go thinner.
  • Copper pour around the trace reduces ΔT by 30–50 % via heat spreading. Most flood pours on 4-layer boards make the formula a lower bound.
  • Plating quality matters — the IPC formula assumes nominal Cu thickness. Boards from cheap fab houses can be 80 % of nominal. Add a margin if you're at the boundary.
  • Don't forget vias — a 0.3 mm drill / 0.5 mm pad via in 1 oz Cu only handles ~0.5 A by itself. See the Via tab.
  • Use IPC-2152 for designs > 5 A — the newer standard gives less-pessimistic widths and accounts for the plane stack-up.

Z₀ vs trace width (current H, εr, T)

Hammerstad — the formula CAD tools actually use

The Hammerstad-Jensen approximation is ±2 % accurate for 0.05 ≤ W/H ≤ 20. Two regimes:

Wide (W/H ≥ 1): Z₀ = (120π / √Eeff) / (W/H + 1.393 + 0.667·ln(W/H + 1.444)) Narrow (W/H < 1): Z₀ = (60 / √Eeff) · ln(8H/W + W/(4H)) Effective ε (for both): Eeff = (εr+1)/2 + (εr-1)/2 · (1 + 12·H/W)^(-0.5) → For wide traces, ε approaches εr; for narrow traces, more field is in air so ε drops.

Where you'll see this

  • USB 2.0 single-ended pull-ups — D+/D− are 90 Ω differential, but the single-ended impedance of each line is ~45 Ω on most stack-ups. Pick W to land on 50 Ω if you're routing one-off signals through the same trace style as USB.
  • HDMI / DisplayPort source termination — series 22 Ω resistors paired with 50 Ω microstrip set the launch impedance for the receiver.
  • RF — Wi-Fi 2.4/5 GHz, BLE, LoRa — every chip antenna feed is 50 Ω microstrip from the IC to the matching network. Width is set by the layer stack — typically 0.3–0.5 mm on 0.2 mm prepreg.
  • SDIO / camera serial buses — 50 Ω single-ended; on a 4-layer 1.6 mm stack with 0.2 mm dielectric, W ≈ 0.35 mm.

What to watch for

  • FR-4 εr is frequency-dependent — 4.5 at 100 MHz, 4.2 at 1 GHz, 4.0 at 5 GHz, and the loss tangent rises with frequency too. Use Rogers / ceramic for > 5 GHz.
  • Copper roughness adds 20–40 % loss at > 5 GHz — standard "FR-4 with 1 oz Cu" has 5 µm roughness. Low-loss boards use "VLP" (very-low-profile) copper at 1 µm.
  • Bends raise impedance locally — 90° corner has ~30 % more inductance per unit length. Use 45° miters or curves above 1 Gbps.
  • Reference plane gaps — if a trace crosses a slit in the reference plane, the return current detours and impedance jumps. Always check that the ref plane is continuous beneath every high-speed line.

The IPC stripline formula

For a symmetric stripline (trace centered between two reference planes separated by total dielectric H, trace thickness T):

Z₀ = (60 / √εr) · ln(4H / (0.67π · (0.8W + T))) Valid for W/(H−T) < 0.35 and T/H < 0.25 (most real designs). Because the field is fully in dielectric, v_p = c/√εr (slower than microstrip). For FR-4, that's ~14.8 cm/ns vs microstrip's ~17 cm/ns. Stripline routes are about 15 % "longer" electrically for the same physical length.

Where you'll see this

  • DDR3/4 buried buses — controller-to-memory address/data lines are routed on inner stripline layers for EMI containment and easier length-matching (no plane gaps to worry about).
  • Backplane / server boards — 8–14 layer stacks bury all high-speed signals; only debug headers and connectors break the surface.
  • RF-shielded inner layers — Wi-Fi / cellular radio modules use stripline on the inner layers to keep the RF section quiet.
  • PCIe Gen3/4/5 — on 4-layer boards Gen3 microstrip is fine; Gen4/5 usually requires 6+ layers with stripline for the high-density routing channels.

Why the formula isn't just "two parallel lines"

A differential pair is two coupled microstrips. The differential mode sees the lines as if grounded between them; the common mode sees them as one trace. The differential impedance is:

Z_diff = 2 · Z₀ · (1 − k) Where k is the coupling factor between the two traces. For edge-coupled microstrip pairs (the common case), a practical fit is: k ≈ exp(−0.96 · S/H)  (S = edge-to-edge spacing, H = dielectric height) → Tight pairs (S/H < 1) have strong coupling; loose pairs (S/H > 3) act nearly independent (k → 0, Z_diff → 2 Z₀).

What to watch for

  • Length-match the pair — intra-pair skew must be < 5 mil (~0.13 mm) for USB 3, < 2 mil for PCIe Gen3+. See the Length-matching tab.
  • Don't separate the lines through the routing — splitting around an obstacle breaks the coupling and turns the diff pair into two single-ended traces. Route them as a unit.
  • AC coupling caps go inline with both traces — 0402 caps with the smallest pads possible. Pad parasitics turn into resonances.
  • Vias matter — every via in a diff pair adds ~50–100 ps and ~5 % impedance discontinuity. For PCIe Gen3+ use back-drilled vias or stay on one layer.
  • P-N skew at vias — going through a via stack-up adds intra-pair skew because each trace passes through the same vias at slightly different heights. Use pre-emphasis or AC coupling to mitigate.

The via as a cylinder

A plated through-hole via is a Cu cylinder. Cross-section is the annulus of copper plating, not the drill hole — the drill is the inside diameter, and Cu deposits on the wall:

A_plating = π · d_drill · t_plating (thin-wall approximation) Apply IPC-2221 with k = 0.048 (treated like external for thermal): I_via = 0.048 · ΔT^0.44 · A^0.725 For 0.3 mm drill × 25 µm plate × 10 °C rise: A = π · 0.3 · 0.025 = 0.0236 mm² = 23.6 × 10³ µm² = 36.5 mil² I = 0.048 · 10^0.44 · 36.5^0.725 ≈ 1.7 A theoretical, ~0.8 A with 50 % derate → Most designers use the derated value — plating quality and board variance make the theoretical answer optimistic.

Where you'll see this

  • Power-rail stitching — feeding a 5 V/2 A rail through a 4-layer board needs ≥ 3 vias from top to inner power plane.
  • GND return for buck/boost — switching node return current needs ≥ 4 vias for any > 1 A load. Spread them across the inductor footprint, not in one cluster.
  • BGA breakouts — 0.4 mm pitch BGA fanout uses 0.2 mm laser-drilled vias (0.3–0.5 A each). Stitch power balls with multiple vias each.
  • Connector pads — USB-PD VBUS (5 A) needs 6–8 stitched vias from the connector pad to the inner power layer.

What to watch for

  • The IPC-2221 via formula is a rough fit — Brooks' original chart did not extend to via geometries. Use ≤ 50 % derate to be safe.
  • Plating thickness varies — fab spec is typically 25 µm minimum but can be ~18 µm in tight spots, or 35–50 µm if you order "heavy plating" (extra cost).
  • Tented vs untented matters at the top — tented (covered) vias dissipate slightly worse since the top of the cylinder can't lose heat to air.
  • Don't put all stitching vias in one row — heat concentrates. Spread vias along the path of current to distribute the heat load.
  • Microvias (laser-drilled blind) — typical 0.1 mm drill / 0.2 mm pad; ampacity ~0.3–0.5 A each. Used in HDI for > 0.4 mm pitch BGA.

What "weight" actually means + why R_sheet is the cleaner unit

Definition: 1 oz Cu = 1 oz spread over 1 ft² Density of Cu: ρ_m = 8.96 g/cm³ 1 oz = 28.35 g; 1 ft² = 929 cm² Thickness = mass / (density · area) = 28.35 / (8.96 · 929) = 34.0 µm  (rounded to 35 µm by IPC) R_sheet = ρ_Cu / t  (electrical resistivity ρ_Cu = 1.68 × 10⁻⁸ Ω·m) For 1 oz: R_sheet = 1.68e−8 / 35e−6 = 0.48 mΩ/square → A square of 1 oz Cu is 0.48 mΩ regardless of size. 10 squares end-to-end = 4.8 mΩ. Easy mental math.

Where you'll see this

  • JLCPCB / PCBWay default = 1 oz outer + 0.5 oz inner on 4-layer. Most hobby boards. Adequate for < 3 A traces.
  • Power-electronics boards typically 2 oz; the higher current capacity + lower R_sheet pay back the extra cost in fewer parallel traces and less voltage drop.
  • BGA breakout sometimes drops to 0.5 oz outer to get etchable 0.10 mm traces. Watch the ampacity tradeoff.
  • EV traction / industrial uses 3–6 oz "heavy copper"; only a few fabs (e.g., Sierra) support > 4 oz with normal lead times.

Where the skew shows up

  • Intra-pair (within a differential pair): converts common-mode to differential-mode noise. Eye closes. Always tighter than inter-pair.
  • Inter-pair / lane-to-lane: between two differential pairs (D+/D− pair to another D+/D− pair). DDR uses byte-lane groups; PCIe handles up to ±20 mil per lane.
  • Byte-lane (DDR-specific): the 8 data lines of one byte must arrive within their strobe (DQS) window. ±25 mil at DDR3, ±10 mil at DDR4.
  • Clock-to-data: source-synchronous interfaces (DDR, SDRAM) need data to arrive within the setup/hold window relative to clock. Often the tightest constraint.

Serpentine routing rules

  • Add length close to the source of mismatch — not at the end of the line. Discontinuities have time to settle if they're upstream.
  • Serpentine amplitude ≥ 3× the trace width — tight bunching couples the trace to itself, slowing the signal locally (paradoxically defeating the length adjustment).
  • Inside-corner vs outside-corner — both legs of an unmatched diff pair should serpentine the same way to keep coupling balanced.
  • Don't serpentine inside a pair for tight protocols (PCIe Gen3+) — use a "bump" pattern (smooth curve) instead.

Memorize

  • 1 oz Cu = 35 µm = 1.4 mil = 0.48 mΩ/□
  • Microstrip on FR-4: ~170 ps/in
  • Stripline on FR-4: ~180 ps/in
  • 50 Ω microstrip ≈ W/H ≈ 1.8 on FR-4 (εr ≈ 4.5)
  • 1 A external, 1 oz, 10 °C: 0.30 mm wide (12 mil)
  • 0.3 mm via @ 25 µm plate: 0.8 A derated

Pitfalls

  • FR-4 εr drifts with frequency (4.5 → 4.0 over 100 MHz–5 GHz)
  • Plating thickness can be 80 % of spec — derate vias
  • Reference-plane gaps under signals = broken impedance
  • Tight serpentines couple to themselves (slow the signal locally)
  • Via barrel cracks under thermal cycling — use multiple
  • Hammerstad valid 0.05 ≤ W/H ≤ 20 (most designs)
