Orthographic Projection — first-angle vs. third-angle

Toggle the projection standard. The same L-bracket fans into six flat views via the "glass box," but where each view *lands* on the page depends on whether the box folds away from the viewer (first-angle / ISO) or toward the viewer (third-angle / ANSI).

What this teaches

An engineer working from an international drawing has to identify the standard *before* reading any dimension. The cone-and-circle symbol in the title block, plus the relative position of the top/front/right views, fully encodes the rule.

Third-angle (ANSI)
cone points right (toward viewer)

What to notice

  • Same part, different page layout. The L-bracket on the left is identical; only the *position* of each flat view on the right depends on the standard.
  • Third-angle (ANSI/US): top view above the front, right view to the right of the front. Mnemonic — the glass box folds *toward* you, so views land where the face is pointing.
  • First-angle (ISO/EU): top view *below* the front, right view *to the left* of the front. The box folds *away* from you, so views land opposite.
  • Title-block symbol is the only unambiguous tell. Cone apex pointing left (toward viewer) = third-angle. Cone apex pointing right (away from viewer) = first-angle.
  • Minimum view set. An L-bracket is fully described by front + top + right. The other three (left, rear, bottom) repeat information and are usually omitted.
  • If you can't tell: assume nothing. Send the drawing back and demand the symbol. Mis-reading the standard rotates every feature 180° in the wrong plane.

Cheat sheet

MEMORIZE

  • 1st angle — ISO / EU. Project AWAY from viewer. Symbol cone points AWAY.
  • 3rd angle — ANSI / US. Project TOWARD viewer. Symbol cone points AT viewer.
  • Front + Top + Right — typical minimum 3-view set.

VIEW SELECTION

  • 3 views — minimum: front + top + right.
  • Section view — when hidden internals matter.
  • Auxiliary view — for inclined / non-orthogonal faces.

COMMON PITFALLS

  • Missing symbol — always include projection-angle symbol in title block; different layouts otherwise give wrong parts.
