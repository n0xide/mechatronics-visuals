Frames & Machines

A truss has only two-force members (each bar pulls or pushes axially). A frame or machine has multi-force members — bars that bend, members with three or more applied loads. To solve them, you take the assembly apart and write equilibrium for each piece, with internal pin forces equal-and-opposite on the two members they connect. Drag the load on the 2-bar linkage; the pin and pivot forces update.

Why frames need disassembly

A truss has 3 equilibrium equations per joint, but each member carries only one unknown (its axial force). That's why method-of-joints works. A frame has members with bending, two or more pin connections, and external loads applied between connections — so a member's free body has 3+ unknowns.

1. Two-force member test — for a bar to carry only an axial load, all external forces must act at exactly two points and be equal-and-opposite. Any third load anywhere → multi-force → bends. 2. A frame typically has only 3 external reactions (≤ 3 unknowns), so the overall FBD is solvable. → Find global reactions first. 3. Then disassemble: separate each member, draw its own FBD with the global reactions on it plus internal pin forces at the joints it shares. 4. At a pin joint shared by two members, Newton's 3rd law: force on member 1 = − force on member 2. So if you call them Bx, By on member AB, they're −Bx, −By on member BC. 5. Each disassembled FBD gives 3 equations. With 2 unknowns per pin (Bx, By), one member's FBD is enough; the second is a check. 6. → Solving order: overall reactions first, then any single member to extract internal pin forces.

Worked example — horizontal beam held by an inclined cable

The setup

A horizontal beam AB of length 0.6 m, pinned at A. A cable runs from B up to point C on the wall directly above A (C is 0.4 m above A). A 500 N vertical load hangs from the midpoint of AB. Find the cable tension and the pin reactions at A.

The cable is a 2-force member (no load along it), so the force it applies at B is purely along the cable direction from B toward C. Cable angle above horizontal: atan(0.4 / 0.6) ≈ 33.7°. Unit vector from B to C: (−0.832, +0.555).

Free body of the beam

External forces on AB: pin reaction at A (Ax, Ay), 500 N down at midspan (0.3, 0), cable tension T pulling B toward C: T·(−0.832, +0.555). ΣFx = 0: Ax + T·(−0.832) = 0 → Ax = 0.832·T ΣFy = 0: Ay + T·(0.555) − 500 = 0 ΣM_A = 0: −500·(0.3) + T·(0.555)·(0.6) = 0  (only the vertical component of T creates moment about A; horizontal component passes through the level of A)

Solve

T = 150 / 0.333 ≈ 451 N (tension) Ax = 0.832 · 451 ≈ +375 N (rightward, +x — the cable at B pulls leftward toward C, so the pin at A must push the beam rightward to keep ΣFx = 0) Ay = 500 − 451·0.555 ≈ +250 N (upward, +y) |A| = √(375² + 250²) ≈ 451 N — same magnitude as T (by coincidence here; the pin generally is whatever it needs to be).

Sign check

Whole-frame ΣFx: Ax (375) + T_x (−0.832·451 = −375) = 0 ✓ Whole-frame ΣFy: Ay (250) + T_y (0.555·451 = 250) − 500 = 0 ✓

Method recap: identify 2-force members first (they simplify to a single scalar along the member), then write equilibrium for each remaining body. Pick the equation that contains the fewest unknowns; usually ΣM about a pin kills two Ax/Ay terms at once.

What to notice

  • Two-force test first, every time — before drawing any FBD, look at each member and ask "does it carry only end-loads?" If yes, you already know the force direction (along the bar) and only need its magnitude. Saves half the work.
  • BC in the example is a 2-force member; AB is not — BC is loaded only at its ends. AB has the midpoint hanging load → 3+ forces → bends. This is the entire reason frames need disassembly.
  • Sign convention discipline — pick "tension positive" or "force on AB at B is +X" and stick to it. The opposite member sees the negation. Half the algebra errors in this topic are sign flips.
  • Pliers, bolt cutters, jacks are machines — they have moving members and convert input force to output force. The math is identical to frames; the only difference is the configuration changes during use, so you solve at one instant.
  • Mechanical advantage = lever ratio — for a pliers, MA = (handle length) / (jaw length). The frame disassembly is what proves it: write moment equilibrium on the handle member, find pin force; on the jaw member, that pin force becomes the input and the jaw force is amplified by the lever ratio.
  • Three equations per member, max — 2D static equilibrium: ΣFx, ΣFy, ΣM. If you have more unknowns than that, you've made the FBD wrong (forgot a force) or the structure is statically indeterminate.

WORKFLOW

  • 1. Sketch overall FBD, label reactions
  • 2. Apply 2-force test to each member
  • 3. Solve global Σ for reactions
  • 4. Pick a multi-force member, draw its FBD
  • 5. Solve for internal pin forces
  • 6. Cross-check on the adjacent member

PITFALLS

  • Drawing pin force only on one side — both members feel it (3rd law). If you forget, equations don't close.
  • Assuming axial when it bends — that midpoint load on AB is the 3rd force. Treat as 2-force only if you've checked.
  • Sign of moment direction — choose CCW = positive (standard) and don't flip mid-problem.
  • Forgetting roller — a roller has only one reaction (perpendicular to surface). A pin has two. Specify on the FBD.
  • Frame is overdetermined — if you have 4 unknowns globally (e.g., 2 pin supports), the system is indeterminate; flexibility or finite-element method needed.
