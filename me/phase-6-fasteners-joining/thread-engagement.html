Thread Engagement Length

Spin a bolt into too few threads and the threads strip before the bolt itself breaks. Too many threads and you waste material and add weight. The rule is: engage the threads so the joint fails in bolt tension, not thread shear. This usually lands at 1·D for steel-in-steel, 1.5·D for steel-in-aluminum, and 2·D for steel-in-plastic. Pick fastener size and material; the visual draws the threads and the failure mode.

Why bolts can either break or strip — and we want them to break

Both failure modes carry the bolt to its load limit. The difference is what happens at that limit.

1. Bolt break: shaft pulls apart in tension. Load drops to zero immediately; sudden, audible. But the threads in the hole are intact — easy to extract the bolt remnant and re-thread. 2. Thread strip: the threads in the hole (or on the bolt) shear off. The hole is destroyed; you'd have to re-tap larger (M4 → M5) or use a thread insert (Helicoil) to recover. 3. Strip-failures are often quiet: you torque the bolt, it doesn't feel right, you torque a little more — and now you have a smooth hole. No clack. The worst kind of failure: silent. 4. → Spec engagement so F_strip > F_bolt: the bolt breaks first, threads survive. 5. Concretely: J = F_strip / F_bolt should be ≥ 1.0 (ideally 1.2–1.5 for safety).

The thread-shear formula

Each engaged thread carries the load over an annular ring of area roughly π · D_pitch · (thread height in tap material). If engagement length is L and pitch is p, the number of engaged threads is n = L / p. Total shear area: A_s = n · π · D_pitch · (p / 2) (the (p/2) is the shear-cylinder height per thread; details vary by formula reference). Strip load: F_strip = A_s · τ_y where τ_y ≈ 0.58 · σ_y (von Mises shear yield). For steel-in-steel of similar strength, J ≥ 1 requires L ≈ D (rule of thumb 1·D). For steel-bolt-in-Al, the Al σ_y is lower → need more L to compensate → 1.5·D. For steel-bolt-in-plastic, σ_y is far lower → need ≥ 2·D, or use a metallic insert.

Worked example — M3 bolt into 3D-printed PLA boss

Direct tap into PLA

PLA tensile yield ≈ 50 MPa, shear ≈ 29 MPa M3 bolt class 8.8: F_bolt = 5.03 mm² × 800 MPa = 4.02 kN For F_strip ≥ F_bolt: A_s ≥ 4020 / 29 = 139 mm² A_s = π · D_p · L · 0.5 = π · 2.675 · L · 0.5 → L ≥ 139 / 4.2 = 33 mm Impractical (longer than typical print thickness). Need an insert.

With brass heat-set insert

Use M3 heat-set insert (e.g., RUTHEX M3): outer Ø 4.6 mm, 5.7 mm long Effective engagement σ_y ≈ 90 MPa (composite brass-in-plastic pullout strength) F_strip = π · D_p · L · τ_y · 0.5 = π · 2.675 · 5.7 · 0.5 × (0.58 · 90) ≈ 1.25 kN Bolt 8.8: F_bolt = 4.02 kN → J = 1.25/4.02 = 0.31 (still strip-limited) Workable for hand-torque tightening (~2 N·m, F_clamp ≈ 1 kN) where you'll never exceed F_strip. Spec: M3 × 6 mm bolt + heat-set insert + max torque 1.5 N·m → clamp load ~750 N, F_strip 1.25 kN → safety factor 1.7

Steel-on-steel reference

Same M3 bolt in tapped steel: F_strip @ L=3 mm = π · 2.675 · 3 · 0.5 × (0.58 · 250) = 1.83 kN @ L=4.5 mm: F_strip = 2.75 kN (>F_bolt for class 4.8 bolts at 2.0 kN) @ L=6 mm: F_strip = 3.66 kN (close to 8.8 bolt at 4.0 kN — J=0.92) Spec: M3 × 6 mm engagement in steel → balanced design, neither strips nor breaks at design load with 30% headroom.

What to notice

  • 1D / 1.5D / 2D rule isn't magic — it comes directly from σ_y ratios. Steel/steel: same σ_y → L ≈ D. Al/steel: Al's σ_y is ~50% of steel-thread strength → need ~1.5× more engagement. Plastic/steel: σ_y is 10% → 2× isn't enough; you need an insert.
  • Bolt-grade affects the ratio — using a class-12.9 bolt in Al threads is a recipe for strip: the bolt is so strong that even 2D engagement won't save the Al. Match bolt strength to substrate.
  • First-engaged thread carries most load — FEA shows the first three threads under the surface carry 60–70% of the load. Beyond 1.5D you're getting diminishing returns; beyond 2D the extra threads contribute almost nothing.
  • Tap drill matters — too-large tap drill → only partial thread height → reduce A_s by ~half → strip at half F_strip. Always use the standard tap drill (D − p for metric ≈ "minor diameter").
  • Coined / rolled threads are stronger than cut threads (cold-work + better grain flow). For high-stress fasteners, spec "thread rolled after heat treatment."
  • Through-hole + nut is foolproof — bolt+nut+washer can never strip the substrate. Use this where possible; tapped holes are weight-saving but more failure-prone.

RULES OF THUMB

  • Steel/steel: L ≥ 1·D
  • Steel/Al: L ≥ 1.5·D
  • Steel/brass: L ≥ 1.5·D
  • Steel/plastic: L ≥ 2·D or insert
  • Class 12.9 bolts need stronger substrate → 2·D in Al
  • Through + nut → never strips substrate

PITFALLS

  • Tap drill too large — partial thread → half F_strip.
  • Forgetting first 3-thread load concentration — extra length beyond 2D adds little.
  • Mixing imperial & metric — different pitch series, different strip math.
  • Re-tap without insert after strip → never as strong as original.
  • Anti-seize on threads reduces friction → at same torque, more clamp force → easier to over-torque and strip.
  • Bottoming tap in blind hole — last 1–2 threads incomplete; don't count those.
