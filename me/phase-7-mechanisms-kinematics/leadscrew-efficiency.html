Leadscrew Efficiency & Back-Drive

A leadscrew is a screw whose job is converting rotary input into linear output (or vice versa). Two numbers dominate its design: lead angle λ (how steep the helix is) and friction coefficient μ. Together they set efficiency (η = how much input power becomes useful linear force) and decide whether the screw is self-locking — staying put when input torque is removed. Slide λ and μ; watch ACME drop below ball-screw and the back-drive threshold appear.

Where the efficiency formula comes from

Imagine "unrolling" one revolution of the screw thread. The helix becomes a ramp: horizontal distance = π·d (one circumference), vertical rise = L (one lead). The ramp angle is λ.

1. tan λ = L / (π · d) (geometric definition of lead angle) 2. Pushing a block up a ramp with friction: F_input acts horizontally; load W acts vertically; friction acts along the ramp surface. 3. Force balance: F_input = W · tan(λ + φ), where φ = atan(μ) is the friction angle. 4. Useful work output per rev: W · L 5. Input work per rev: F_input · π · d = W · π · d · tan(λ + φ) 6. η = (W · L) / (W · π · d · tan(λ+φ)) = tan λ / tan(λ + φ) 7. Lowering (load drives screw): reverse the friction direction. η_lower = tan(λ − φ) / tan λ. 8. When λ < φ (friction-angle exceeds lead-angle), tan(λ − φ) is negative → load can't drive the screw at all → SELF-LOCKING.

The self-lock criterion

Self-locking screws stay put when input torque is removed. Useful for jacks, vises, leveling screws, lift gates. The criterion is simple:

Self-locking ↔ μ > tan λ ↔ φ > λ Examples: ACME L=8mm, d=10mm → λ = atan(8/(π·10)) = 14.3°. μ_steel-bronze ≈ 0.10 → φ = 5.7° → NOT self-locking. ACME L=2mm, d=10mm → λ = 3.6°. μ ≈ 0.10 → φ = 5.7° → self-locking ✓ Ball-screw L=10mm, d=20mm → λ = 9.0°, μ ≈ 0.005 → φ = 0.3° → never self-locks. (Use a brake.) → Low-lead ACME = self-locking but slow. High-lead ACME = fast but back-drives. Ball-screw = fast and efficient but never self-locks.

Worked example — 3D-printer Z-axis

The constraint

FDM printer Z-axis must hold ~3 kg gantry against gravity when power is off (motor coils unenergized). Z-axis steppers can hold by themselves (microstep detent), but if a thermistor failure cuts power mid-print, you don't want the gantry crashing into the print.

Lead options

Common 3D-printer Tr leadscrews: Tr8×2 (8mm dia, 2mm lead), Tr8×4, Tr8×8 μ for steel + brass nut: 0.10–0.15 (graphite-greased)

Tr8×2 (slow but safe)

λ = atan(L/(π·d_m)) ≈ atan(2/(π·8)) ≈ 4.55° using nominal d = 8 mm as an approximation. (Strictly: Tr8 mean diameter d_m ≈ 7 mm → λ ≈ atan(2/(π·7)) ≈ 5.2°. The qualitative conclusions below are unchanged.) μ = 0.12 → φ = 6.84° → λ < φ → self-locking ✓ η_up = tan(4.55°)/tan(11.39°) = 0.395 → 39.5% efficient η_down = tan(4.55° − 6.84°)/tan(4.55°) = negative → can't back-drive (formula confirms self-lock) Verdict: holds gantry on power-off. Slow Z-move; OK because Z moves only between layers.

Tr8×8 (fast, but check)

λ = atan(8/(π·8)) = 17.66° μ = 0.12 → φ = 6.84° → λ > φ → NOT self-locking η_up = tan(17.66°)/tan(24.5°) = 0.702 → 70% efficient η_down = tan(17.66° − 6.84°)/tan(17.66°) = 0.602 → back-drives at 60% energy recovery Verdict: gantry will fall on power-off. Add a brake or use a stepper that always holds power.

Decision

Most printers use Tr8×8 (fast Z for travel moves) with a continuously-energized Z stepper. If you want a fast, back-drive-safe Z, use ball-screws + electromagnetic brake.

What to notice

  • Ball-screws double the efficiency — μ drops from 0.10 (sliding ACME) to ~0.003 (rolling balls). At λ = 10° that turns η = 50% into η = 95%. For long, fast travels (a 1 m machine moves a lot), this saves real energy and heat.
  • Steep lead = fast + unsafe — slope of the helix is the lead angle. Steeper means more linear motion per revolution, but also easier to back-drive. Steep + low friction = fast but never holds.
  • Self-lock is friction-limited, not gravity-limited — a hydraulic jack screws stays up at 5000 lb only because friction prevents back-drive; the load isn't holding it down. If you lubricate too well, the jack falls.
  • Heat is the bill for friction — A 30% efficient ACME at 100W input puts 70W into heat. For continuous operation (motorized linear actuator), this heat will limit the nut life — bronze starts degrading at 150 °C, polymer at 100 °C.
  • Ball-screws need a brake — they back-drive freely; a small load makes them unwind. If safety requires "stays put on power-off," add a magnetic brake (50-200 USD) or use an ACME screw.
  • Planetary roller screws split the difference — efficiency near ball-screw, no recirculation = silent + smoother, but cost is 3-5× ball-screw. CNC machine spindles use these.

Cheat sheet

FORMULAS

Lead angle
tan λ = L / (π·d)
Friction angle
φ = atan(μ)
η (lift)
tan λ / tan(λ + φ)
η (lower)
tan(λ − φ) / tan λ
Torque (lift)
T = F · d/2 · tan(λ + φ)
Self-lock
φ > λ ↔ μ > tan λ

SCREW TYPES

  • ACME / Tr: μ ≈ 0.10–0.20
  • ACME, fine lead: self-locking
  • Ball-screw: μ ≈ 0.003, never self-locks
  • Roller screw: μ ≈ 0.01
  • Lubricant matters — grease cuts μ by 30–50%
  • Worm gear obeys same equations

PITFALLS

  • Assuming any screw self-locks — only fine-lead ACME does reliably.
  • No brake on ball-screw — vertical loads will fall; add electromagnetic brake.
  • Wet vs dry μ — water on ACME drops μ from 0.12 to 0.05 — and the jack falls.
  • Pitch vs lead — single-start: pitch = lead. Multi-start: lead = n × pitch.
  • Static vs kinetic μ — at startup, μ_s is higher (lock holds). After moving, μ_k is what η uses.
  • Thrust bearings still needed — efficiency formula doesn't include the axial thrust bearing friction.
